# あんなことこんなことClaude

Claudeの活用方法を、手順・そのまま使えるプロンプト・つまずきやすい点まで、同じ形式で整理する静的サイトです。難易度(初心者向け・中級者向け)、目的、使う機能のタグで探せます。

個人が運営する非公式のサイトで、Anthropic社とは関係ありません。

## 構成

| パス | 内容 |
|---|---|
| `content/tips/` | 活用方法の原稿(Markdown) |
| `content/news/` | 「Claude最新情報」の原稿(Markdown) |
| `data/queue.json` | 掲載予定の活用方法の一覧と順序 |
| `config/site.json` | サイト名、難易度・目的・機能のタグ、広告・アフィリエイトの設定 |
| `build.py` | 原稿から `docs/` を生成するスクリプト(Python 3、標準ライブラリのみ) |
| `check.py` | 公開前チェック |
| `docs/` | 生成されたサイト(GitHub Pagesで公開) |

## ビルドとチェック

```
python3 build.py            # docs/ を再生成
python3 build.py --next     # 次に書く活用方法を表示
python3 check.py --visual   # 公開前チェック(スマホ幅の横スクロールも確認)
```

## 活用方法の原稿の書式

`content/tips/<slug>.md` の先頭にメタ情報を書きます。

```
---
title: タイトル
level: beginner            # beginner(初心者向け) / intermediate(中級者向け)
minutes: 15                # 所要時間の目安(分)
purpose: organize          # config/site.json の purposes の id
features: projects, files  # config/site.json の features の id(カンマ区切り)
output: 作れるもの
summary: 一文の説明
added: 2026-10-30          # ページを追加した日
updated: 2026-10-30        # 情報を確認した日
next: 別の活用方法のslug    # 「つぎに試すなら」に出す(任意)
books:
- 書名 | 著者・出版社 | ISBN13
sources:
- 情報源のタイトル(何の確認に使ったか) | URL
---
```

本文は `##` の見出しで区切ります。活用方法には、次の見出しが必須です(`check.py` が確認します)。

`ねらい` / `準備するもの` / `手順` / `そのまま使えるプロンプト` / `うまくいかないとき`

本文の部品:

| 書き方 | 内容 |
|---|---|
| `:::flow 見出し` + 行ごとに `見出し \| 補足` | 手順の流れ(番号つき) |
| `:::prompt 見出し` + 貼る文章 | そのまま使える文章(コピーボタンつき) |
| `:::compare 見出し` + 1行目が表の見出し、以降は `左 \| 右` | 比較表 |
| `:::note 見出し` + 文章 | 注意書き |
| `:::` | ブロックの終わり |

`sources` が空だとビルドは止まります。機能の仕様、提供プラン、上限は、公式のヘルプ・発表で確認して書きます。確認できないことは書きません。

## 「Claude最新情報」の原稿の書式

`content/news/<日付>-<slug>.md` に書きます。メタ情報は `title` / `date`(発表日) / `summary` / `features` / `added` / `updated` / `next` / `sources`。本文の見出しは `何が発表されたか` / `できるようになること` / `活用方法` / `注意すること` を含めます。出典は、公式の発表を必ず1件以上入れます。

## 書くときのルール

- 公式の情報を言い換えて書きます。長い引用はしません。
- 手法そのものが新しくなくてもよい活用方法は、確認日(`updated`)を入れます。機能・画面は変わるため、「画面の表示は変わることがあります」と添えます。
- 収益や成果の保証、「必ずうまくいく」のような断定はしません。
- 「毎日更新」など、更新の頻度は、公開ページに書きません。
- 「調べた情報源」に書店の書誌情報(`書誌情報` を含む題名で、URLにISBN、または書名が対応するもの)を入れると、ビルド時に、Amazonのアフィリエイトリンクに自動で切り替わる(確認に使った書店のリンクも併記)。
- 紹介本は3冊ほど。候補がなければ載せません。ISBNは、書店などの書誌情報で確認してから書きます(`check.py` がチェックデジットも確認します)。
- 個人情報、別サイトの運営情報は書きません。
