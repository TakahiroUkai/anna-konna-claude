Designで、ポスターの案を3つ作る

ClaudeのDesignで、案内ポスターの案を3つ並べて比べ、コメントと直接編集で仕上げる方法です。印刷に出す前に確かめること、共有の範囲、使い切りに注意する点まで整理します。

難易度中級者向け 設定や考え方の理解が少し要る。いくつかの機能を組み合わせる。

結論から書きます。ポスターは、1枚を何度も直すより、最初に「同じ内容で見た目の違う案を3つ」頼んで、選んでから直すほうが早く決まります。選ぶ作業は、直す作業より軽いからです。

「町内会の掲示板に貼る案内を頼まれたが、デザインが苦手」。そんな人に、そのまま見せられる方法です。

ねらい

  • Design(Claudeの中で、画面やチラシなどの見た目を作る機能)で、案内ポスターの案を3つ作ります。
  • 修正を、チャット・コメント・直接編集に使い分けます。
  • 書き出す前に、確かめる項目を決めておきます。

準備するもの

  • Claudeのアカウント。公式ヘルプには、Free、Pro、Max、Ultra、Team、Enterpriseで使え、初期設定でオンと書かれています(2026年11月10日に確認)。
  • ポスターに入れる文字(題名、日時、場所、連絡先)。連絡先は、練習では作り話にします。
  • 使いたい写真やイラストがあれば、自分で撮った、または使ってよいと分かっているものだけにします。
  • 注意: 公式ヘルプには、Designは、これまでの独立した画面(claude.ai/design)が2026年12月14日に終わると書かれています。既存のプロジェクトは段階的に移されます。以前の作品を使う人は、公式ヘルプで案内を確認します。

手順

  1. 会話で、Designで作りたいと頼みます。公式ヘルプには、入力欄の「Output」から「Design」を選ぶ方法も書かれています。
  2. 最初の指示には、公式ヘルプの勧めに沿って、目的、レイアウト、内容、見る人を書きます。足りない情報は、Claudeが質問します。
  3. 出てきた3案を比べます。
  4. 直し方は、公式ヘルプでは次のように使い分けると書かれています。配色の変更や、2〜3案の提示のような広い変更はチャット。キャンバス上の特定の場所はインラインコメント。見た目の細かい調整は、ドラッグやリサイズなどの直接編集です。
  5. 「Export」から書き出します。公式ヘルプには、.zip、PDF、PPTX、Googleスライド、単体のHTMLが書かれています。

画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事のプロンプトは、この文章を書いた環境では実際に動かせていません(Claudeの画面でDesignを使う操作が必要なためです)。そのため、出力は載せません。自分で動かしたときの確かめ方を書きます。

  • 3つの案の文字を、依頼した文字と1字ずつ見比べます。日時と連絡先は特に見ます。
  • 画面を最小まで縮めて、題名が読めるかを見ます。
  • 書き出したPDFを開いて、画面で見た配置とずれていないかを見ます。

使いどころと失敗例

向く場面は、見た目の案をまず並べて、決めたい場面です。掲示、案内、簡単なチラシなどです。

向かない場面は、印刷所に出す入稿データ(裁ち落としなどを含む)が必要なときです。公式ヘルプには、ポスター用の印刷形式や、PNG・JPEGでの書き出しの記載はありませんでした。印刷は、書き出したPDFを、家やコンビニで試し刷りして確かめてからにします。

よくある失敗と、その直し方です。

  • 文字が勝手に言い換えられる。 「この文字は変えない」と書き、見直しのプロンプトで1字ずつ確かめます。
  • 全体を頼んで、気に入っていた部分まで変わる。 1か所の直しは、コメントで頼みます。
  • 前の案に戻れない。 公式ヘルプには、Designにはまだ版の履歴がない、と書かれています。大きく変える前に、「今の状態を保存して、別の方向を試して」と頼みます。
  • コメントが消える。 公式ヘルプには、コメントが表示されないことがあるため、その場合はチャットに貼って頼む、と書かれています。
  • 何度も作り直して、上限を使い切る。 公式ヘルプには、Designは他のClaudeの利用(Claude Codeを含む)と同じ利用上限を共有し、大きなプロジェクトや多くのやり直しは多く使う、と書かれています。案は3つまでに絞ります。

うまくいかないとき

  1. エラー「chat upstream error」が出る。 公式ヘルプには、同じプロジェクトの中で、新しいチャットのタブを開くよう書かれています。
  2. 共有の範囲が気になる。 作った直後は自分だけが見られます。「Share」で、見る、コメントする、編集する、の権限を選びます。スマホのアプリでは共有設定を変えられません。個人の連絡先を載せたものは、広く共有する前に消すか伏せ字にします。
  3. 同時に何人かで直すと不安定。 公式ヘルプには、複数人での同時編集は基本的な機能で、確実に動かないことがある、と書かれています。直す人は1人にします。
  4. 印刷した色が画面と違う。 画面と紙で色は変わります。この記事では、色の合わせ方は確認できませんでした。試し刷りで確かめます。

確認できなかったこと(印刷用の形式、色の合わせ方)は、この記事では決めつけません。
