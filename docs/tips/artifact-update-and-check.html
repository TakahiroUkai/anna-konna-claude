Artifactを更新して、前の版と見比べる

作ったArtifactを直すときは、直す前の版を控えとして残し、Claudeに変更点の表を出させて、元の版と見比べます。公式のヘルプで確かめた直し方と、確かめられなかった点を分けて整理します。

結論から書きます。Artifactを直すときは、直す前に「控え」を残し、直したあとに「変更点の表」を出させます。この2つだけで、「直したつもりが、直してほしくない所まで変わっていた」を見つけられます。

「ClaudeにWebページの文言だけ直してもらったら、ボタンの色まで変わっていた」という同僚に、この手順を渡せます。

ねらい

  • Artifact(会話の横に作られる、ツール・文書・ページなどの作品)を、安全に直す手順を身につけます。
  • 直す前の版を残し、変更点を表にして、元の版と見比べます。
  • 公式のヘルプで確かめられたことと、確かめられなかったことを、分けて知ります。

準備するもの

  • 直したいArtifactが1つ。
  • 20分ほどの時間。
  • 公式のヘルプには、Artifactを使うには、設定の「Capabilities」で「Cloud code execution and file creation」(新しい設定画面では「Create and edit files」)を有効にする必要があると書かれています。
  • 画面の表示は変わることがあります。

手順

  1. 直す前の版を、控えとして残します。 公式のヘルプには、Docs・Slides・Designなどの形式のArtifactは、「Export」で書き出せると書かれています。文書はWord、PDF、Markdown、Google Docs、スライドはPowerPointとPDF、などです。古い形式のArtifactは、上部のボタンで、コードの表示・コピー・ダウンロードができると書かれています。どのArtifactにも同じ方法があるかは、確認できませんでした。
  2. 直す範囲を伝えます。 公式のヘルプには、Claudeに変更を頼むと書かれています。文書やMarkdownでは、直したい文を選んで「Edit with Claude」を押し、頼みを書く方法があり、選んだ場所をClaudeが直すと書かれています。他の形式で、同じ部分指定ができるかは、確認できませんでした。そのため、頼む文章で範囲を言葉で指定します。
  3. 変更点の表を出させます。 下のプロンプトを使います。変えた所だけでなく、「変えていない所」も書かせるのがコツです。
  4. 表と実物を見比べます。 表に「変えていない」と書いてある所が、本当に同じかを、控えと並べて確かめます。Claudeの説明は、実物の代わりになりません。
  5. 直しすぎたときは、戻します。 公式のヘルプには、前のメッセージを編集すると、別の流れ(それぞれ自分のArtifactを持つ)ができ、前の作業を失わずに別の方向を試せると書かれています。ただし、これは会話の枝分かれの説明です。1つのArtifactの履歴をたどる機能(バージョン履歴)の説明は、このページでは確認できませんでした。控えを残す理由は、ここにあります。

2つの版を並べて表示する機能があるかは、公式のヘルプで確認できませんでした。この記事の「見比べる」は、控えと、変更点の表と、実物を、自分の目で照らし合わせる方法です。

そのまま使えるプロンプト

実際の出力例

この記事を書いた環境では、読者のArtifactを直して動かすことができませんでした。作り話の出力を載せないため、出力は載せません。

自分のArtifactで試すときの確かめ方です。

  • 「変えていない所」の表に書かれた項目を、控えと並べて、1つずつ目で確かめます。
  • 表に無い所が変わっていないかも、控えと見比べます。
  • 食い違いがあれば、その点を伝えて、直してもらいます。

使いどころと失敗例

向く場面は、すでに動いているArtifactの一部だけを直したいときです。ページの文言、表の列、計算式などの直しに向きます。

向かない場面は、作り直しに近い大きな変更です。その場合は、新しいArtifactとして作り、古い版は残したままにします。

よくある失敗と、その直し方です。

  • 控えを残さずに、直す。 直したあとで、元の版が見られなくなることがあります。先に書き出すか、コピーを取ります。
  • 「ここだけ直して」とだけ頼む。 範囲が曖昧だと、他の所も変わることがあります。「変えないこと」を書きます。
  • 表を信じて、実物を見ない。 表はClaudeの説明です。実物と照らし合わせます。
  • エラーが出たときに、何度も直しを頼む。 公式のヘルプには、エラーの近くに「Try fixing with Claude」があると書かれています。ただし、直るとは限らないとも書かれています。直らないときは、控えに戻して、頼み方を変えます。

うまくいかないとき

  • 「Edit with Claude」が見つからないとき: 公式のヘルプでは、文書やMarkdownの文を選んだときに出ると書かれています。他の形式では、確認できませんでした。この場合は、頼む文章で範囲を指定します。
  • 書き出せないとき: 書き出せる形式は、Artifactの種類で違います。出ないときは、コードの表示とコピーの操作があるかを見ます。それもなければ、内容を貼り付けて、別のファイルに保存します。
  • データを保存するArtifactのとき: 公式のヘルプには、保存するデータは、作った人が、個人用の保存か共有の保存かを決めると書かれています。機密の情報を入れる前に、共有の保存かどうかを確かめます。
  • 公開した古い形式のArtifactを直すとき: 公式のヘルプには、公開を取り消すと、保存したデータが完全に消えると書かれています。取り消す前に、必要なデータを書き出します。
  • 使えるプラン: 公式のヘルプには、Artifactは、Free、Pro、Max、Ultra、Team、Enterpriseで使えると書かれています。データを保存する機能は、Freeは載っていませんでした。画面の表示は変わることがあります。
