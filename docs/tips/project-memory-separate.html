プロジェクトごとにメモリを分けて、混ざりを防ぐ

プロジェクトごとにメモリが分かれる、という公式の説明を、架空の目印を使って自分のアカウントで確かめます。「Use account memory」の切り替え、消すときの注意、うまく分かれないときの切り分けまで書きます。

結論から書きます。プロジェクトのメモリは、公式のヘルプによると、プロジェクトごとに分かれます。ただし、初めの設定のままで「完全に」分かれるとは書かれていません。分かれ方は、架空の目印を使って、自分のアカウントで確かめます。

「仕事の案件が3つあって、Claudeが別の案件の前提を持ち出してくる」と困っている人に、そのまま見せられる点検です。

ねらい

  • プロジェクトのメモリが、どこまで分かれるのかを、目印テストで確かめます。
  • 「Use account memory」を切り替えたときの違いを、自分の目で見ます。
  • 混ざったときに、原因を1つずつ外して探せるようにします。

準備するもの

  • 公式のヘルプ(2026年11月17日に確認)によると、メモリは、Free、Pro、Max、Ultraで初めからオンです。TeamとEnterpriseでは初めはオフで、オーナーが有効にします。自分のプランと設定は、画面で確かめます。
  • 公式のヘルプには、HIPAA対応、公的機関向け、独自の保持契約のある組織では、メモリは使えない、と書かれています。該当する場合は、管理者に確かめます。
  • 試し用のプロジェクトを2つ(名前は「テストA」「テストB」など)。実際の案件では試しません。
  • 目印には、架空の言葉を使います。実在の人名、住所、仕事の内容は入れません。
  • 30分と、翌日にもう一度見る時間。

手順

  1. 目印を決めます。 たとえば、「テストAの合言葉は、あおいみかん」のような、意味のない言葉です。
  2. テストAで、覚えてもらいます。 「この合言葉を、このプロジェクトのメモリに覚えて」と頼みます。
  3. 別の場所で聞きます。 テストBと、プロジェクトの外のチャットで、「テストAの合言葉は?」と聞きます。公式のヘルプによると、他のプロジェクトのメモリは使われません。プロジェクトの外については、次の手順で確かめます。
  4. 設定を変えて、もう一度聞きます。 公式のヘルプによると、プロジェクトの中のClaudeは、そのプロジェクトのメモリと、プロジェクトの外のチャットで作られたアカウントのメモリを使います。完全に分けたいときは、プロジェクトのページの「Memory」にある「Use account memory」をオフにする、と書かれています。
  5. 表にします。 「どの場所で、合言葉が出たか」を、下の表に書きます。
  6. 翌日にも見ます。 メモリが反映される早さは、公式のヘルプには書かれていませんでした。確認できなかったので、翌日にも同じ質問をします。

そのまま使えるプロンプト

実際の出力例

この記事のプロンプトは、この文章を書いた環境では、実際のアカウントで動かせていません(メモリが、自分のアカウントのものだからです)。そのため、出力は載せません。自分で動かしたときの確かめ方を書きます。

  • 合言葉が出たとき、Claudeが「メモリにある」と答えたのか、「今の会話で聞いた」と答えたのかを分けて読みます。
  • 「知りません」と答えたのに、あとで出てくる、という動きがないかを、翌日にも見ます。
  • 結果は、必ず自分の画面で、「設定 > Memory」を開いて、メモリの項目と見比べます。Claudeの「消しました」「設定を変えました」という答えは、信じません。

使いどころと失敗例

向く場面は、案件や科目ごとに、前提(取引先、決まり、文体)が違うときです。プロジェクトごとにメモリを持つので、別の案件の前提が混ざりにくくなります。

向かない場面は、1回だけの相談です。その場合は、「+」のメニューでメモリをオフにするか、インコグニートチャット(プロジェクトの外で使える、履歴にもメモリにも残らないチャット)を使います。

よくある失敗と、その直し方です。

  • テストをしないまま、実際の案件を入れた。 先に、架空の目印で確かめます。
  • チャットを消せば、メモリも消えると思った。 公式のヘルプには、チャットを消しても、そこから作られたメモリは残る、と書かれています。メモリの項目を、自分で消します。
  • 「リセット」を気軽に押した。 公式のヘルプには、プロジェクトのメモリを含めて、すべてのメモリが消え、元に戻せない、と書かれています。押す前に、必要な項目を控えます。
  • 機微な話題(健康、政治、宗教など)が、入らないと思った。 公式のヘルプには、初めの設定では、機微な話題はメモリに入らず、「Include sensitive topics in memory」で入れる設定にできる、と書かれています。その設定をオンにしたかどうかを、確かめます。
  • 共有したプロジェクトの、メモリの扱い。 共有されたプロジェクトで、メモリがどう扱われるかは、読んだ公式のページに書かれていませんでした。確認できなかったので、仕事の秘密や個人情報は、共有するプロジェクトでは、メモリに入れません。

プロジェクトを消したときに、そのメモリがどうなるかは、読んだ公式のページに書かれていませんでした。確認できませんでした。残したくない内容は、先にメモリの項目として消してから、プロジェクトを消します。

うまくいかないとき

  1. 別のプロジェクトの合言葉が出た。 切り分けは、次の順に、1つずつ外します。(1)そのチャットで、「+」のメモリがオンか。(2)プロジェクトの「Use account memory」はオンか。(3)合言葉を、今の会話の中で、自分が書いていないか。(4)プロジェクトの外のチャットで、同じ合言葉を話していないか。
  2. 何も覚えていない。 設定のメモリがオフか、一時停止中かもしれません。公式のヘルプには、一時停止中は、既存のメモリは残るが、使われず、新しいメモリも作られず、その間の会話は、あとから足されない、と書かれています。
  3. メモリが見つからない。 「設定 > Memory」の「Topics」を開きます。公式のヘルプの、古い画面の説明は、場所が違います。
  4. チームの管理者が、使えるようにしていない。 TeamとEnterpriseでは、初めはオフです。公式のヘルプには、オーナーは、個人のメモリの中身を見られない、と書かれています。使えるかどうかは、管理者に聞きます。
  5. 過去のチャットを探すと、別のプロジェクトが出ない。 検索は、プロジェクトの外と、各プロジェクトの中で、別々です。仕様どおりです。

つぎに試すなら

  • メモリと過去チャット検索の範囲を点検して、残すものを決める

    Claudeのメモリと過去チャット検索が、どこまでを覚え、どこまでを探せるのかを、公式のヘルプをもとに整理します。プロジェクトごとの分け方、1つのチャットだけ外す方法、チャットを消してもメモリが残る点、点検の手順と確かめ方まで書きます。
