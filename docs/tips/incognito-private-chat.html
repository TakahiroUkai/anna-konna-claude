インコグニートチャットで、残したくない相談をする

履歴にもメモリにも残らないインコグニートチャットの開き方と、向く相談・向かない相談を整理します。閉じると戻れない点、プロジェクトの中では使えない点、保持される期間まで、公式のヘルプで確かめた範囲で書きます。

結論から書きます。インコグニートチャットは、履歴とメモリに残さずに話せる、使い捨てのチャットです。ただし、閉じると戻れません。大事な答えは、閉じる前に、自分で控えます。

「サプライズの準備や、言い出しにくい話の練習を、あとから自分の履歴に残したくない」という友人に、そのまま見せられる手順です。

ねらい

  • インコグニートチャットの開き方と、終わらせ方を覚えます。
  • 残さずに話したい場面と、残したほうが便利な場面を分けます。
  • 「残らない」の範囲(履歴、メモリ、検索)を、公式のヘルプの言葉で確かめます。

準備するもの

  • Claudeのアカウント。公式のヘルプ(2026年11月17日に確認)によると、インコグニートチャットは、Free、Pro、Max、Ultra、Team、Enterpriseのすべてのプランで使えます。
  • パソコンのブラウザか、Claudeデスクトップ。公式のヘルプに、手順が書かれているのは、この2つです。スマホの手順は、確認できませんでした。
  • 10分ほどの時間。

手順

  1. プロジェクトの外で、新しいチャットを開きます。 公式のヘルプには、プロジェクトの中では使えない、と書かれています。
  2. 右上の幽霊のアイコンを押します。 インコグニートが、オンになります。
  3. 画面を確かめます。 公式のヘルプによると、黒い枠と、左上の「Incognito chat」の表示が出ます。出ていなければ、オンになっていません。
  4. 話します。 控えたい答えは、この時点で、メモ帳などに写します。
  5. 右上の「x」で終わります。 公式のヘルプには、終わらせたチャットは、再び開けず、ふつうのチャットに変えることもできない、と書かれています。

画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事のプロンプトは、この文章を書いた環境では、インコグニートチャットで動かせていません。そのため、出力は載せません。自分で動かしたときの確かめ方を書きます。

  • 閉じたあと、チャット履歴に、その会話が出ないことを見ます。
  • 新しいふつうのチャットで、「さっきの話の続きを」と頼んでも、内容が出てこないことを見ます。出てきたら、インコグニートがオンになっていなかった可能性があります。
  • 答えのうち、控えたい部分が、自分のメモにあることを、閉じる前に見ます。

使いどころと失敗例

向く場面は、次のとおりです。

  • 贈り物や、お祝いの準備など、あとで見られたくない下準備。
  • 言い出しにくい話の練習。
  • 今回だけの話で、メモリに「好み」として覚えてほしくないとき。

向かない場面は、続きの作業です。履歴に残らず、再び開けないので、何日かかけて進める作業には向きません。そのときは、通常のチャットか、プロジェクトを使います。

よくある失敗と、その直し方です。

  • 終わらせてから、答えを控え忘れた。 戻れません。次からは、「x」を押す前に、写します。
  • 「何も残らない」と思い込んだ。 公式のヘルプには、安全のため、初めの設定では30日間は保持される、と書かれています。ほかの人に見られたくない話、法律に関わる話などは、インコグニートでも、書き込まないほうが安全です。
  • プロジェクトの中で、アイコンが見つからない。 プロジェクトの中には、ありません。公式のヘルプには、代わりに「+」のメニューで、最初のメッセージの前に「Memory」をオフにする方法が書かれています。ただし、そのチャットは、履歴に残り、検索の対象にもなります。
  • ファイルを作ってほしい、コードを動かしてほしい。 公式のヘルプには、新しい画面を使っている場合、インコグニートは、前の画面で開き、ファイルの作成やコードの実行ができない、と書かれています。

「+」のメニューでメモリをオフにしたチャットは、履歴に残り、検索でも見つかります。メモリに使わないだけです。履歴にも残したくないときは、インコグニートです。

うまくいかないとき

  1. 幽霊のアイコンが見つからない。 プロジェクトの外の、新しいチャットで探します。すでに話し始めたチャットにはありません。
  2. 黒い枠が出ない。 オンになっていません。アイコンをもう一度押します。
  3. ファイルが作れない。 上の失敗例のとおり、前の画面で開くためです。通常のチャットで、機密でない内容にして頼みます。
  4. スマホで開き方が分からない。 公式のヘルプには、スマホの手順が書かれていませんでした。確認できなかったので、この記事では決めつけません。
  5. 「保持される」ことが気になる。 保持の期間と、学習への扱いは、公式のヘルプのリンク先(プライバシーセンター)で、自分のプランの説明を読んで確かめます。

使い分けの全体を見直すときは、「メモリと過去チャット検索の範囲を点検して、残すものを決める」へ進みます。

つぎに試すなら

  • メモリと過去チャット検索の範囲を点検して、残すものを決める

    Claudeのメモリと過去チャット検索が、どこまでを覚え、どこまでを探せるのかを、公式のヘルプをもとに整理します。プロジェクトごとの分け方、1つのチャットだけ外す方法、チャットを消してもメモリが残る点、点検の手順と確かめ方まで書きます。
