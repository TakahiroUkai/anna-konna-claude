Docsで、レポートの骨組みから作る

いきなり本文を書かせると、読み手に合わない長い文章になりがちです。Claude Docsで、先に「骨組み(見出しと各節のねらい)」だけを作り、直してから本文を書いてもらう手順をまとめました。誰が読むか、何を決めたいかを先に伝えるのがコツです。

レポートや報告書は、いきなり本文から書き始めると、途中で「何を言いたいのか」がぼやけます。ここでは、Claude Docs(会話の中で作れる、文書づくりの機能)を使って、先に骨組みだけを作り、直してから本文を書いてもらいます。

ねらい

  • 見出しと、各節で言うことを1行ずつ決めた「骨組み」を作ります。
  • 骨組みを自分で直してから、本文を書いてもらいます。
  • 読み手に合わせた文書を、Word・PDFなどで書き出せる形にします。

準備するもの

  • 文書の目的(何を決めてほしいか、何を伝えたいか)。
  • 読む人(上司、取引先、先生など)と、その人が知っていること。
  • 材料になるメモや資料(あれば)。個人情報や、社外に出せない情報は入れません。

公式のヘルプによると、Docsは、Free、Pro、Max、Team、Enterpriseの各プランで使えます(Enterpriseは、組織の管理者の設定で変わります)。画面の表示は変わることがあります。

手順

Docsの作り方は、公式のヘルプでは次のように説明されています。

  • 会話で文書を頼む。または、依頼の頭に「/docs」を付ける。または、メッセージ欄で「Output」から「Docs」を選ぶ。
  • Artifactsの画面で、Docsのテンプレートを選んで、作りたい文書を説明する。

ヘルプには、Claudeが先に確認の質問をすることや、作った理由をコメントで残すことも書かれています。「骨組みを先に作る」という手順そのものは、ヘルプに書かれた機能ではありません。プロンプトでお願いする、ここでの進め方です。

そのまま使えるプロンプト

うまくいかないとき

  • 骨組みなのに本文まで書いてしまうとき: 「本文はまだ書かないでください。見出しと1行の説明だけ」と、もう一度、はっきり頼みます。
  • 材料にない数字が入っているとき: 「材料に書かれていない数字をすべて挙げてください」と頼み、見つかったものは消すか、自分で確かめます。
  • 図表(グラフ)が古くなったとき: 公式のヘルプによると、図表は自動では更新されません。数字を直したら、Claudeに図表の更新を頼みます。
  • 共有について: 公式のヘルプによると、Docsは最初は自分だけが見られます。「共有」ボタンから、閲覧のみ、または編集もできる人を選べます。Free、Pro、Maxでは、リンクを知っている人に共有できます。Team、Enterpriseでは、組織の外への共有はできないと書かれています。
  • 削除について: 公式のヘルプによると、削除できるのは作成者だけで、削除すると元に戻せません。消す前に、書き出しておきます。
