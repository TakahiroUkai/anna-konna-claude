メモリと過去チャット検索の範囲を点検して、残すものを決める

Claudeのメモリと過去チャット検索が、どこまでを覚え、どこまでを探せるのかを、公式のヘルプをもとに整理します。プロジェクトごとの分け方、1つのチャットだけ外す方法、チャットを消してもメモリが残る点、点検の手順と確かめ方まで書きます。

結論から書きます。Claudeの「覚える」と「探せる」は、別の仕組みで、消し方も別です。チャットを消しても、そこから作られたメモリは残ります。だから、設定を1回見直して、「残す話」と「残さない話」の線を先に決めておくと安心です。

「仕事の相談も家のことも、同じアカウントで話している」という友人に、そのまま見せられる点検です。

ねらい

  • メモリ(会話をまたいで好みや前提を覚える機能)と、過去チャット検索の違いを、1枚の表で分けて理解します。
  • 自分の設定を、画面で点検します。
  • 話の種類ごとに、「通常のチャット」「プロジェクト」「1つだけメモリを外す」「インコグニート」を使い分ける線を決めます。

準備するもの

  • 公式のヘルプ(2026年11月12日に確認)によると、メモリは、Free、Pro、Max、Ultraで初めからオンです。Team、Enterpriseでは、オーナーが使えるかどうかを管理します。過去チャット検索は、有料プランが対象です。自分のプランは、画面で確かめます。
  • 設定を開く時間を10分ほど。
  • 点検のあいだは、メモリの内容を人に見せない場所で行います。

手順

  1. 2つの機能を分けます。 下の表で、覚える機能と探す機能の違いを見ます。
  2. 設定を開きます。 公式のヘルプには、「設定 > Your Claude」に、メモリ全体の「Generate memory from chats」と、検索の「Search and reference chats」があると書かれています。古い設定画面では、場所が違うと書かれています。
  3. メモリの中身を読みます。 公式のヘルプには、「Your memory」の「Manage」から、項目の一覧を開き、編集や削除ができると書かれています。思っていないことが入っていないかを見ます。
  4. 線引きを決めます。 下の「線引きの表」を、自分用に埋めます。
  5. 確かめます。 新しいチャットで、覚えさせたいことを伝えて、次のチャットで反映されるかを見ます。

画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事のプロンプトは、この文章を書いた環境では実際に動かせていません(点検には、自分のアカウントのメモリの中身が必要なためです)。そのため、出力は載せません。自分で動かしたときの確かめ方を書きます。

  • 表の判断が、自分の感覚と合っているかを見ます。「迷う」に入った項目は、自分で決めます。
  • Claudeが「消しました」「設定を変えました」と答えたら、信じません。設定の変更は、自分の画面でしか確かめられません。
  • 使い分けの表に、公式のヘルプに無い説明(たとえば「必ず安全」)が入っていないかを見ます。入っていたら、「公式で確かめられる範囲に直してください」と頼みます。

使いどころと失敗例

向く場面は、アカウントを仕事と私用で分けずに使っているとき、人に画面を見せる機会があるとき、機微な話題(健康、お金、家族)を相談することがあるときです。

よくある失敗と、その直し方です。

  • チャットを消したのに、メモリに残っている。 公式のヘルプには、新しい方式では、チャットを消しても、そこから作られたメモリは消えない、と書かれています。メモリは「Manage」から、個別に消します。
  • メモリをオフにしても、データの書き出しから消えない。 公式のヘルプには、メモリはデータの書き出しに含まれ、オフにしても消えない、と書かれています。消したいときは、中身を削除します。
  • 1つのチャットだけオフにしようとして、あとから変えられない。 公式のヘルプには、始めたチャットのメモリの設定は、あとから変えられない、と書かれています。話し始める前に決めます。
  • 「消す」と「リセット」を取り違える。 公式のヘルプには、「Reset memory」は、プロジェクトのメモリを含めてすべてを完全に消し、取り消せない、と書かれています。使う前に、必要な項目を別に控えます。
  • プロジェクトを消して、中のメモリも消える。 公式のヘルプには、プロジェクトを消すと、そのプロジェクトのメモリも消える、と書かれています。

公式のヘルプには、健康、人種・民族、宗教、政治、性自認などの機微な話題は、初めは保存されない、と書かれています。「設定 > Your Claude」の「Include sensitive topics in memory」で、保存するかを選べます。保存するようになった場合は、保存のたびに通知が出ると書かれています。確認したうえで、自分の判断で選びます。

うまくいかないとき

  1. 設定の場所が違う。 古い設定画面では、「Settings > Memory」や「Settings > Capabilities」に、同じ機能があると書かれています。
  2. Team・Enterpriseで、メモリが使えない。 公式のヘルプには、組織のオーナーが管理すると書かれています。オーナーは、個人のメモリを見たり、編集したりできない、とも書かれています。
  3. プロジェクトのメモリを、完全に分けたい。 公式のヘルプには、プロジェクトのページの「Memory」で、「Use account memory」をオフにする、と書かれています。
  4. 覚えてほしいのに、覚えない。 チャットの中で「これを覚えて」と頼めると、公式のヘルプに書かれています。覚えたかは、「Manage」の一覧で確かめます。
  5. 政府発行のID番号や口座番号を覚えさせたい。 公式のヘルプには、これらは頼んでも保存されない、と書かれています。入力しないのが安全です。

確認できなかったこと(保存のしくみの細かい動き、保存までにかかる時間)は、この記事では決めつけません。必要な場合は、自分の画面と、公式のヘルプで確かめてください。
