Whiteboardsの発想を、担当と期限つきの計画にする

Claude Whiteboardsに出した発想を、計画案(文書)に変えます。担当と期限は人が決める、という線引きと、抜けや順番のずれを確かめる手順、共有と書き出しの注意点まで書きます。

結論から書きます。ボードから計画を作るときは、Claudeに「作業の順番と抜け」を出してもらい、「担当」と「期限」は人が入れます。Claudeは、公式のヘルプによると、ボードの内容だけで作り、つないだアプリの予定や空き状況は使いません。

「アイデアは出たのに、誰がいつやるかが決まらないまま会が終わった」と悩んでいる人に、そのまま見せられる手順です。

ねらい

  • 発想のボードを、作業の順番がある計画案にします。
  • 担当と期限が空いている行を、見落とさずに洗い出します。
  • 直し方と、送り先(共有・書き出し)の注意点を、先に決めておきます。

準備するもの

  • 発想が書かれたClaude Whiteboardsのボード。「Whiteboardsで、ふりかえりの意見をテーマ別に整理する」で作ったボードでも使えます。公式のヘルプ(2026年11月15日に確認)によると、ベータで、Pro、Max、Ultra、Team、Enterpriseが対象です。
  • 担当者の候補と、期限の目安(自分で決めた日付)。
  • 公式のヘルプには、HIPAA対応の構成の組織では使えない、と書かれています。該当する場合は、使う前に管理者に確かめます。
  • 個人情報、社外に出せない情報は、ボードに入れません。

手順

  1. ボードを見直します。 同じ内容が2か所にないか、1つの項目に作業が2つ入っていないかを見ます。
  2. 計画案にしてもらいます。 公式のヘルプには、「このボードを、プロジェクトの計画にして」のように頼むと、文書や資料に変えられると書かれています。
  3. 空欄を洗い出します。 下のプロンプトで、担当と期限が決まっていない行を、先に出してもらいます。
  4. 担当と期限を入れます。 Claudeは、ボードの内容だけで作ります。誰の予定が空いているかは、Claudeには分かりません。人が決めます。
  5. 順番のずれを点検します。 「Bの前にAが終わっている必要がある」といった関係が、逆になっていないかを見ます。公式のヘルプには、依存する項目をつなぐ、と書かれていますが、つなぎ方が正しいかは、自分の目で確かめます。
  6. 送ります。 「Share」から招く、画像(PNG)で書き出す、「Send to」で、Lucid、Miro、Zoho Vaniに送る、の3つが、公式のヘルプに書かれています。

画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事を書いた環境では、Claude Whiteboardsの画面を操作できませんでした。そのため、実際の出力は載せません。

出力は、次の3点で確かめます。

  • 「未定」の行の数が、自分で数えた空欄の数と同じか。
  • 「(案)」と付いた行が、ボードの内容から外れていないか。外れていたら、採用するかを自分で決めます。
  • 「前に終える作業」を、紙に書いた順番と見比べて、逆がないか。

使いどころと失敗例

向く場面は、アイデアが20個ほど出て、実行の順番を決めたいときです。

向かない場面は、日程の調整です。公式のヘルプには、ボードの内容だけから作り、つないだアプリの情報は使わない、と書かれています。カレンダーを見ながら決めたいときは、「コネクタで、予定を見ながら1日の計画を立てる」を使います。

よくある失敗と、その直し方です。

  • Claudeが、期限を推測で埋める。 プロンプトで「推測で埋めない」と書き、「未定」と出させます。
  • 「(案)」の作業を、そのまま採用する。 案は、チームで採用を決めます。
  • 共有した相手が、ボードを並べ替えた。 公式のヘルプには、共有した人も、同時に並べ替えられると書かれています。送る前に、PNGで控えを残します。
  • 組織の外の人を招けない。 公式のヘルプには、管理者が「Organization settings > Artifacts」で、組織外へのメール招待をオンにする必要がある、と書かれています。
  • 送り先のアプリに、内容が残る。 「Send to」で送った先の扱いは、その各サービスの規約によります。この記事では確認していません。送る前に、送り先の規約を確かめます。

計画がおかしいときは、「ボードの抜け」「Claudeの並べ方」「自分が入れた担当・期限」の3つを、1つずつ外して見ます。いきなり「全部直して」と頼むと、原因が分からなくなります。

うまくいかないとき

  1. 計画案に、ボードの内容が入っていない。 「ボードにあって、計画案に入っていない作業を、一覧にして」と頼みます。
  2. 担当が勝手に入っている。 「担当を、全部『未定』に戻して」と頼みます。
  3. 範囲が広すぎて、答えが曖昧。 公式のヘルプには、ボードの一部をドラッグで囲んで、その部分について聞ける、と書かれています。範囲を狭めて聞きます。
  4. 「Send to」の先に出てこない。 公式のヘルプで確かめられた送り先は、3つだけです。そのほかは、PNGで書き出します。
  5. 使えない、または表示が違う。 ベータで、プランや組織の設定によって違います。管理者に確かめます。

確認できなかったこと(盤面の項目数の上限、元に戻す機能、送り先での保存の扱い)は、この記事では決めつけません。公式のヘルプと、自分のボードで確かめてください。
