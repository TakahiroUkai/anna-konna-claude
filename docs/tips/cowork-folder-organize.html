ホーム

Coworkで、フォルダの整理案を作ってもらう

Coworkに、散らかったフォルダの整理案を先に作らせ、確かめてから実行させる方法です。削除はさせず、移動の記録を残し、件数で結果を確かめます。

結論から書きます。フォルダの整理は、「実行させる」前に「整理案の表を作らせる」と、失敗がほとんど防げます。移動の記録を残せば、あとから元に戻せます。

「ダウンロードフォルダが、いつの何か分からないファイルだらけ」。そんな人に、そのまま見せられます。Claudeに任せる範囲を、1つのフォルダに絞って試します。

ねらい

  • 散らかったフォルダの中身を読んで、整理案を表にしてもらいます。
  • 案を自分で確かめてから、移動だけを実行してもらいます。
  • 移動の記録を残し、結果を件数で確かめます。

準備するもの

  • 有料プランと、Claudeのデスクトップアプリ。公式ヘルプには、Coworkは有料プラン(Pro、Max、Ultra、Team、Enterprise)で使えると書かれています(2026年11月9日に確認)。
  • 試すためのフォルダ1つ。最初は、デスクトップ全体ではなく、ダウンロードなどの1フォルダに絞ります。Claudeの公式の使い方ページにも、全体が不安なら1フォルダから始める案内があります。
  • 試す前に、そのフォルダのコピーを別の場所に取っておきます。
  • 用語の説明: Coworkは、パソコン上のファイルなどを使って、複数の手順の作業を任せる機能です。権限モードは、Claudeが、聞かずに動いてよい範囲を決める設定です。

手順

  1. Coworkで、試すフォルダを選びます。公式ヘルプによると、Claudeが読み書きできるのは、自分が接続したフォルダだけです。
  2. 1つ目のプロンプトで、整理案の表だけを作らせます。
  3. 表を読み、「迷う」と書かれたファイルや、移動先が合わないものを直します。
  4. 2つ目のプロンプトで、移動を実行させます。
  5. 3つ目のプロンプトで、件数を合わせます。

権限モードは、チャット欄のモードの選択から変えられます(公式ヘルプ)。最初は、聞いてから動くManualにします。Skip(確認なしで動く)は、関わるものをすべて信頼できるときだけ、とヘルプにあります。画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事のプロンプトは、この文章を書いた環境では実際に動かせていません(Coworkの画面と、手元のフォルダが必要なためです)。そのため、出力は載せません。自分で動かしたときは、次のように確かめます。

  • 1つ目のあとで、表の行数が、フォルダのファイル数(OSの表示)と合っているか。
  • 2つ目のあとで、「移動の記録.csv」の行数が、移動した数と合っているか。
  • 3つ目のあとで、整理前の総数と、整理後の総数が同じか。ちがう場合は、ちがう数と該当のファイル名が出ます。
  • 気になる移動は、記録の「元の場所」を見て、手で戻します。コピーを取ってあれば、見比べられます。

使いどころと失敗例

向く場面は、種類で分けられる程度の散らかりで、ファイルの数が多くて手作業が重いときです。向かない場面は、仕事の書類のように、置き場所に意味や決まりがあるときです。意味は、Claudeには分からないことがあります。

よくある失敗と、その直し方です。

  • 一度に広い範囲を渡す。 1フォルダに絞り、うまくいってから広げます。
  • 案を見ずに実行させる。 1つ目で必ず表を作らせ、「迷う」が多いなら、先に分け方を決め直します。
  • 「いらないものは消して」と頼む。 公式ヘルプには、完全に削除する前にはClaudeが許可を求めるとあります。それでも、削除は頼まず、「確認待ち」に移して、自分で消します。
  • 記録を残さない。 記録がないと、元の場所が分からなくなります。2つ目の条件を消さないでください。

うまくいかないとき

  • 表が長すぎて読めないとき: 「種類ごとに、先頭の10件だけ」と頼み、傾向を見てから広げます。
  • 移動先が合わないとき: 移動先の名前を、自分で3〜4個決めて渡し、「この中から選ぶ」と条件を足します。
  • 途中で止まったとき: 画面で承認を待っていないかを見ます(サイドバーのしるしで、確認を待つ作業が分かるとの案内が、Claudeの使い方ページにあります)。再開は、「移動の記録.csv にあるものは動かさず、残りだけ続けて」と頼みます。
  • 機密のファイルが混ざっているとき: そのファイルは、別のフォルダに移してから試します。Coworkの安全についての注意は、公式ヘルプの「Use Cowork safely」にあるので、事前に読んでください(この記事では、その本文は確認していません)。
  • ファイルの保存先について: 公式の資料によって、ファイルがどこで処理されるかの説明が異なって見えました。個人情報や機密のファイルは、このフォルダに入れないでください。

つぎに試すなら

  • 大きな作業を、チェックリストに分けて進める

    一度では終わらない大きな作業を、段階に分け、各段階に「終わりの条件」をつけて進める方法です。最後に進捗メモを作らせ、会話が変わっても続きから始められます。確かめるのは自分です。
