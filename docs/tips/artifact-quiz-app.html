Artifactで、自作のクイズアプリを作る

覚えたい内容を渡して、Artifactで「答えると○×が出て、最後に点数が出る」クイズアプリを作る方法です。資料を読み返すより、答えるほうが弱い所が見えます。

資格の勉強や、新しい業務の用語。読み返すだけでは、覚えたかどうか分かりません。そこで、覚えたい内容を渡して、答えると○×が出るクイズアプリを作ってもらいます。作ったアプリは、会話の横で動きます。

ねらい

  • 覚えたい内容から、10問の4択クイズを作ります。
  • 答えるたびに○×と解説が出て、最後に点数が出るアプリにします。
  • 作ったあとで「間違えた問題だけ、もう一度」などの直しを、言葉で頼みます。

準備するもの

  • 覚えたい内容。箇条書きのメモでも、教科書の一部を貼った文章でもかまいません。
  • 問題の数と難しさ(例: 10問、基本レベル)。
  • Claudeで、ファイルを作る設定が入っていること。公式のヘルプによると、Artifactを使うには「設定 > 機能」の中の、ファイルの作成と編集の項目がオンである必要があります。名前は画面の更新で変わることがあります(「Cloud code execution and file creation」、新しい画面では「Create and edit files」と書かれています)。
  • 個人情報や、社外に出せない内容は貼らないでください。

Artifact(アーティファクト)は、会話の横に作られる作品のことです。公式のヘルプでは、文書、スライド、ダッシュボード、小さな操作ツールなどが例に挙がっています。作ったものは、左のメニューの「Artifacts」タブに保存されます(確認日時点)。

手順

そのまま使えるプロンプト

うまくいかないとき

  • 画面にエラーが出たとき: 公式のヘルプによると、エラーの近くに「Try fixing with Claude」(Claudeに直してもらう)が出ます。直る保証はないと書かれています。直らなければ、出たエラーの文章を、そのまま貼って頼みます。
  • 解説がまちがっていそうなとき: 解説は、Claudeが作った文章です。試験や仕事で必要な内容は、元の資料と見比べて確かめます。
  • 問題が内容から外れるとき: 「書かれていることだけから作る」の条件が入っているか、確かめます。
  • 作り直したくなったとき: 気に入らない所だけを、言葉で直してもらいます。一度にたくさん頼むより、1つずつのほうが、結果を確かめやすくなります。画面の表示は変わることがあります。
  • 友だちにも使わせたいとき: 共有の方法は、公式のヘルプの別の記事にまとめられています。共有する前に、貼った内容に個人情報が入っていないかを見直します。この記事では、共有の手順は確認していません。
