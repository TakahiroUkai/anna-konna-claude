パソコン版Claudeを入れて、最初の1回を試す

パソコン版Claude(Claude Desktop)を、MacやWindowsに入れて、サインインし、最初の1回の会話を試すまでの手順です。公式のヘルプで確かめられた対応OSと、有料プランの違いも整理します。

ブラウザでClaudeを使っている人が、パソコン版(Claude Desktop)を入れると、アプリとして起動できるようになります。この記事では、入れて、サインインして、短い依頼を1つ試すところまでを、15分で終えます。

「ブラウザのタブが多くて、Claudeを探すのが面倒だ」という人に、そのまま渡せる手順です。

ねらい

  • 自分のパソコンが、パソコン版Claudeに対応しているかを確かめます。
  • 入れて、サインインして、最初の依頼を1つ試します。
  • 有料プランの人が使える機能と、Freeプランの違いを知ります。

準備するもの

  • Claudeのアカウント(メールアドレスなど、サインインに使うもの)。
  • 対応OSのパソコン。公式のヘルプによると、Macはバージョン13(Ventura)以上、Windowsは10以上です。Linuxは、ベータ版として提供されています(確認日時点)。
  • 試す内容。個人情報や、社外に出せない内容は入れないでください。

手順

  1. 対応を確かめます。 Macはバージョン13以上、Windowsは10以上です。
  2. ダウンロードします。 公式のヘルプには、claude.ai/downloadから、OSに合ったものをダウンロードする、と書かれています。
  3. 入れて、起動します。 ダウンロードしたファイルを開いて入れます。Macは「アプリケーション」フォルダから、Windowsはスタートメニューから起動する、と書かれています。
  4. サインインします。 アカウントでサインインします。
  5. 最初の依頼を試します。 下のプロンプトを送ります。

Linuxは、ベータ版で、入れ方が違います(公式のヘルプでは、aptリポジトリから入れる方法が、推奨として書かれています)。この記事では、Linuxの手順は扱いません。画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事を書いた環境では、パソコン版Claudeを入れて操作することができませんでした。そのため、パソコン版での実際の出力は載せません。

自分で試すときは、次の点で確かめます。

  • 午前と午後に分かれていて、時刻が書かれていないもの(見積もりの返信、買い物)に、時刻が勝手に付いていないか。
  • 持ち物が、メモにない物まで書かれていないか。
  • ブラウザ版と、返事の質に大きな差が出ないか。公式のヘルプには、ブラウザ版との違いの一覧は、書かれていませんでした。

使いどころと失敗例

向く場面は、毎日Claudeを使い、ブラウザのタブから探す手間を減らしたいときです。公式のヘルプには、Claude CodeとClaude Coworkも、パソコン版で、有料プランの人が使えると書かれています。

向かない場面は、IT担当者が方針を決めている会社のパソコンです。入れてよいかを、先に確かめます。

よくある失敗と、その直し方です。

  • 対応していないOSに入れようとする。 Macは13以上、Windowsは10以上です。先にバージョンを見ます。
  • 更新のペースを、自分で選べると思っていた。 リリースチャネル(更新を受け取るペースの選択)は、MacとWindowsで、設定の「Desktop app」にあります。既定の「Stable」で足ります。IT担当者が設定しているパソコンでは、選べません。
  • うまくいかないときに、入れ直す。 公式のヘルプには、一般的な困りごとの解説は、書かれていませんでした。更新の確認は、Macは「Claude > Check for Updates」、Windowsは「Help > Check for Updates」です。入れ直す前に、パソコンの中のデータを、保存してください。

うまくいかないとき

  1. ダウンロードしたファイルが開けない。 自分のOSに合うものを、claude.ai/downloadから取り直します。OSのバージョンが対応しているかも見ます。
  2. サインインできない。 この記事で読んだ公式のページには、サインインの失敗についての案内は、書かれていませんでした(確認できませんでした)。ブラウザ版で同じアカウントでサインインできるか、試します。
  3. Claude CodeやClaude Coworkが見当たらない。 Freeプランでは使えません。プランを確かめます。
  4. 更新が来ない。 更新の確認を、手で実行します。リリースチャネルの変更は、次の更新確認のときに反映される、と書かれています。

確認できなかったこと(サインインの失敗の直し方、ブラウザ版との機能の違いの一覧)は、この記事では決めつけません。公式のヘルプと、自分の画面で確かめてください。
