ホーム

Whiteboardsで、ふりかえりの意見をテーマ別に整理する

ふりかえりで出た意見を、Claude Whiteboardsに書き出して、テーマ別に並べ直してもらいます。公式のヘルプで確かめた使い方と、そのまま貼れるプロンプト、出た結果の見直し方まで書きます。

結論から書きます。ふりかえりの意見は、「まず全部書き出す」「テーマ別に並べ直してもらう」「足りない所を聞く」の3回に分けると、15分でまとまります。並べ直しは、Claudeに頼めます。

「ふりかえりの会が、いつも意見の読み上げで終わってしまう」と困っている人に、そのまま見せられる手順です。

ねらい

  • バラバラに出た意見を、テーマごとのまとまりにします。
  • 「話すこと」と「あとで決めること」を、ボードの上で分けます。
  • 会の最後に、次に話す3点を決められる状態にします。

準備するもの

  • Claude Whiteboards(会話の横に作る、共有できる考え整理用のボード)。公式のヘルプ(2026年11月15日に確認)によると、ベータで、Pro、Max、Ultra、Team、Enterpriseのプランが対象です。Enterpriseは、管理者が設定でオンにするまで使えません。
  • ふりかえりで出た意見。10〜20個を目安にします。短い文でかまいません。
  • 個人名や、社外に出せない情報は書かずに、「Aさん」のように置き換えておきます。

手順

  1. ボードを作ります。 公式のヘルプには、チャットで「ふりかえりのためのホワイトボードを作って」のように頼む方法と、Artifactsの画面で「Whiteboard」を選ぶ方法が書かれています。
  2. 意見を渡します。 下のプロンプトを使います。声で伝えたいときは、送信ボタンの横のマイクで読み上げる方法もあると、公式のヘルプに書かれています。
  3. テーマ別に並べ直してもらいます。 公式のヘルプには、テーマ別に並べ直す、時系列に直す、といった頼み方が例に挙がっています。
  4. 足りない所を聞きます。 公式のヘルプには、2つの手順の間に何が足りないかを聞くと、提案がボードに加わる、と書かれています。加わった提案は、そのまま使わず、自分の目で見て選びます。
  5. 一部の範囲だけ質問します。 公式のヘルプには、ボードの一部をドラッグで囲んで、その部分について聞ける、と書かれています。

画面の表示は変わることがあります。

そのまま使えるプロンプト

実際の出力例

この記事を書いた環境では、Claude Whiteboardsの画面を操作できませんでした。そのため、実際の出力は載せません。

確かめ方は次のとおりです。

  • 渡した意見の数と、ボードに並んだ意見の数が同じかを数えます。減っていたら、「その他」に入っていないか、探します。
  • 言葉が書き換わっていないかを、3つほど選んで見比べます。
  • テーマ名を見て、自分の感覚と合うかを確かめます。合わなければ、「このテーマ名を、別の言い方にして」と頼みます。

使いどころと失敗例

向く場面は、意見が10〜20個ほど出ていて、まだ分類が決まっていないときです。

向かない場面は、数字で比べる決めごと(予算、日程)です。ボードは、考えを整理する道具です。数字の検算は、別の表で行います。

よくある失敗と、その直し方です。

  • テーマ名で、話した気になる。 テーマ名は、整理の入り口です。中の意見を、声に出して読みます。
  • 1つの意見が、複数のテーマにまたがる。 無理に1か所に置かず、「どちらにも関係する」と書いて、会で話します。
  • 提案を、そのまま採用する。 ボードに加わった提案は、Claudeの案です。チームの事情に合うかは、人が決めます。
  • 個人名を書いてしまった。 公式のヘルプには、共有すると、ボードの中の人が同時に並べ替えられると書かれています。共有の前に、名前や、社外に出せない情報が残っていないかを見直します。

公式のヘルプには、組織の外の人を招くには、管理者が「Organization settings > Artifacts」で、組織外へのメール招待をオンにする必要がある、と書かれています。招く前に、相手と範囲を確かめます。

うまくいかないとき

  1. 「Whiteboard」が見つからない。 ベータで、プランや組織の設定によって、使えるかが違います。Enterpriseは、管理者がオンにするまで使えません。管理者に確かめます。
  2. 意見が減った。 「元の意見の数と、ボードの意見の数を数えて、差があれば、どれが無いかを書いて」と頼みます。
  3. テーマが、細かすぎる。 「テーマを、3つ以内にまとめ直して」と頼みます。
  4. 書き出したいが、形式が分からない。 公式のヘルプには、PNG(画像)に書き出せると書かれています。そのほかの形式は、確認できませんでした。
  5. 使用量が気になる。 公式のヘルプには、通常のプランの使用量に数えられると書かれています。

確認できなかったこと(盤面に置ける項目の数、元に戻す機能、データの保存期間)は、この記事では決めつけません。公式のヘルプで確かめてください。
