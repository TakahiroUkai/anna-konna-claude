Web検索で、気になる情報の裏付けを取る

「本当かな?」と思った話を、そのまま信じも捨てもせずに、出典つきで確かめる方法です。主張を分けて、1つずつ出典をつけてもらい、最後は自分で出典を開いて確かめます。

「この食べ物は体にいいらしい」「この制度が来月変わるらしい」。メッセージやニュースで流れてきた話を、本当かどうか確かめたい場面は多くあります。ここでは、Claudeに「Web検索」を使ってもらい、話を1つずつ分けて、出典つきで裏取りします。Claudeの答えを結論にせず、出典を自分で開いて確かめるところまでが手順です。

ねらい

  • 気になる話を、確かめられる主張に分けます。
  • 主張ごとに、出典と「確認できた・できない」を並べたメモにします。
  • 「確認できませんでした」と言ってもらうことで、わからないことをわからないまま残します。

準備するもの

  • 確かめたい話(メッセージ、記事の一文、聞いた話など)。個人情報は消して貼ります。
  • Web検索が使える状態のClaude。公式のヘルプでは、チャット欄の「+」ボタンから「Web search」を選び、チェックが付けばオンになると説明されています。一方で、新しい画面ではオン・オフの切り替えがなく、役に立つときにClaudeが自分でWebを検索する、とも書かれています。自分の画面で確かめてください。画面の表示は変わることがあります。
  • 組織(TeamやEnterprise)のアカウントでは、管理者が先にWeb検索を有効にする必要がある、と公式のヘルプに書かれています。

手順

公式のヘルプには、検索させたいときはプロンプトに「Web検索を使って」のように書けること、複数の出典を求めると広く見渡せること、重要な情報は挙げられた出典を自分で照らし合わせること、が書かれています。このページの手順は、これをもとにしています。

そのまま使えるプロンプト

うまくいかないとき

  • 検索されていないように見えるとき: 「Web検索を使って」と書き足します。画面にオン・オフの切り替えがあるときは、オンになっているか確かめます。
  • 出典のリンクが開けないとき: 公式のヘルプには、ウェブサイトのリンクが動かないことがある、と書かれています。ページの題名で検索し直してもらうか、別の出典を求めます。
  • 地域に合わない結果が出るとき: 公式のヘルプによると、地域に合わせた結果を求めたとき、IPアドレスから推測した位置情報を使うことがあります。「日本の制度について」のように、対象をはっきり書きます。
  • すぐに上限が近づくとき: 無料のアカウントには使用量の上限があり、Web検索や長い記事の読み込みも上限に数えられる、と公式のヘルプに書かれています。長い記事は全文を貼らず、確かめたい一文だけを貼ります。
  • 結論が出ないとき: 「確認できませんでした」は、失敗ではなく、1つの結果です。わからなかった主張だけを残し、元の発信者や公式の窓口に直接たずねるのも一つの方法です。
  • 医療・お金・法律の話のとき: Claudeの整理は、判断の材料にとどめます。最終的な判断は、専門家や公式の窓口の案内も確かめたうえで、自分で行います。
