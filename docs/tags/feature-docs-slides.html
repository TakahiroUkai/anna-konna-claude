Docs・Slides・Design

文書、スライド、デザインを作る。4件の活用方法があります。

  • Docsで、文書を直しながら一緒に書く

    Claudeの「Docs」で文書を作り、直接の編集、チャットでの依頼、コメントでの@Claudeを使い分けて仕上げる方法です。共有の範囲と、消すと戻せない点まで確かめてから渡します。

    中級者向け約25分書くDocs・Slides・Design基本のチャット

  • Designで、ポスターの案を3つ作る

    ClaudeのDesignで、案内ポスターの案を3つ並べて比べ、コメントと直接編集で仕上げる方法です。印刷に出す前に確かめること、共有の範囲、使い切りに注意する点まで整理します。

    中級者向け約25分作るDocs・Slides・Design基本のチャット

  • Docsで、レポートの骨組みから作る

    いきなり本文を書かせると、読み手に合わない長い文章になりがちです。Claude Docsで、先に「骨組み(見出しと各節のねらい)」だけを作り、直してから本文を書いてもらう手順をまとめました。誰が読むか、何を決めたいかを先に伝えるのがコツです。

    初心者向け約15分書くDocs・Slides・Design基本のチャット

  • メモからスライドを作って、PowerPointで書き出す

    箇条書きのメモをClaudeに渡して、スライドの下書きを作り、PowerPointやPDFで書き出す方法です。直し方のコツと、書き出す前の点検リストもまとめました。
