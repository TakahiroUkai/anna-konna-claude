初心者向け

Claudeを使い始めた人でも、画面の操作だけで試せる。。13件の活用方法があります。

  • 相手と目的を伝えて、メールの下書きを作る

    「メールを書いて」だけで頼むと、ありきたりな文面になりがちです。相手、目的、言いたいこと、避けたいことを先に伝えて、下書きを作ってもらう方法をまとめました。

    初心者向け約10分書く基本のチャット

  • Projectsに資料と指示を入れて、毎回の説明をなくす

    同じ話題で何度もClaudeに相談するとき、背景の説明を毎回書き直さなくて済むように、資料と指示をProjectにまとめておく方法です。

    初心者向け約15分整理するProjectsファイルの読み込み

  • Artifactで、割り勘の計算ツールを作る

    作りたいツールを言葉で伝えるだけで、会話の横に動くツールができます。割り勘の計算ツールを例に、作り方と、直し方、共有する前の注意点を整理します。

    初心者向け約15分作るArtifacts基本のチャット

  • 長い文章を貼って、要点と疑問点を出してもらう

    長い記事や資料を、全部読む前に「何が書いてあるか」「どこが怪しいか」をつかむ方法です。貼る・添付するの2通りと、読み違いを減らす聞き方をまとめました。

    初心者向け約10分学ぶ基本のチャットファイルの読み込み

  • decisions.mdに、決めた理由を残して、後で迷わないようにする

    「なぜそう決めたか」を、decisions.mdに1行ずつ残す方法です。後から見直すとき、Claudeにも前提を渡せます。

    初心者向け約10分整理する基本のチャットProjects

  • glossary.mdに、言葉の表記をそろえて、ぶれをなくす

    「活用方法」と「使い方」のように、ぶれやすい言葉を、glossary.mdで統一する方法です。

    初心者向け約10分書く基本のチャットProjects

  • ideas.mdに、案をためて、Claudeと選び分ける

    思いついた案を、ideas.mdにいったんためておき、Claudeと「やる・待つ・やめる」に分ける方法です。

    初心者向け約10分整理する基本のチャット

  • log.mdに、やったことを日付つきで残して、続きから始める

    log.mdに、毎回の作業を数行ずつ残すと、翌日の続きがすぐ始められます。書く項目と、Claudeの使い方をまとめます。

    初心者向け約10分整理する基本のチャットProjects

  • README.mdに、構成と手順を書いて、Claudeに読ませる

    README.mdに、構成・手順・書式を書いておくと、人にもClaudeにも、作業の入口になります。書く項目と、読ませ方をまとめます。

    初心者向け約15分整理する基本のチャットファイルの読み込みClaude Code

  • rules.mdに、書くときの約束をまとめて、毎回守らせる

    「断定しない」「数字は出典を付ける」など、毎回伝えている約束を、rules.mdに1度まとめて、Claudeに守ってもらう方法です。

    初心者向け約15分書く基本のチャットProjects

  • sources.mdに、確認済みの出典をまとめて、毎回の調べ直しをなくす

    よく使う公式ページや、確認した書誌情報を、sources.mdにまとめて、確認した日つきで残す方法です。

    初心者向け約10分調べる基本のチャットファイルの読み込みWeb検索

  • style.mdに、文体の決まりを書いて、文章の調子をそろえる

    文の長さ、使わない言葉、見出しの型を、style.mdに書いて、Claudeの文章の調子をそろえる方法です。

    初心者向け約15分書く基本のチャットProjects

  • todo.mdに、やることを書き出して、優先順位をClaudeと決める

    頭の中のやることを、todo.mdに書き出してClaudeに渡し、今日やることを3つに絞る方法です。

    初心者向け約10分整理する基本のチャットファイルの読み込み
