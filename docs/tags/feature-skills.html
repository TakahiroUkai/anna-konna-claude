  • くり返す手順を、スキルにまとめて自動で呼び出す

    毎回プロンプトを貼り直している作業を、スキル(手順書のフォルダ)にまとめる方法です。書く項目、ZIPにする形、呼び出されないときの見直し方、信頼できないスキルを入れるときの注意を、公式のヘルプをもとに整理しました。

このサイトについて 個人が運営する非公式のサイトです。Anthropic社とは関係ありません。「Claude」はAnthropic社の商標です。

ご利用にあたって 一般的な情報の整理であり、結果を保証するものではありません。機能、画面、料金、提供プランは変わることがあるため、各ページの出典(公式情報)と、お使いの画面で確認してください。AIの答えには誤りが含まれることがあります。大事な内容は、自分で確かめてから使ってください。

広告について このサイトには、書籍紹介のアフィリエイトリンク(広告)が含まれます。リンク先で購入されると、運営者に報酬が入ることがあります。Amazonのアソシエイトとして、あんなことこんなことClaudeは適格販売により収入を得ています。
