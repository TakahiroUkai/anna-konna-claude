ファイルの読み込み

文書や画像を渡して読んでもらう。12件の活用方法があります。

  • CSVを渡して、集計とグラフをArtifactで作る

    家計や売上のCSVをClaudeに渡して、集計表とグラフを会話の横に作る方法です。分析ツールの設定、集計が合っているかの確かめ方、うまくいかないときの切り分け、貼ってはいけないデータの線引きまで整理します。

    中級者向け約25分作るArtifactsファイルの読み込み

  • 資料からクイズを作って、自分で練習する

    講義資料やテキストをClaudeに渡して、答え合わせつきのクイズを作り、間違えた所だけを復習する方法をまとめました。自分がどこで間違えるかが見えるので、読み返しの時間を絞れます。

    初心者向け約15分学ぶ基本のチャットファイルの読み込み

  • Projectに複数の資料を入れて、役割を分けて使わせる

    Projectに資料を何でも入れると、答えの根拠が見えなくなります。資料に役割を決めて入れ、指示で使い分けさせ、根拠のファイル名を答えに付けさせる方法を、公式のヘルプをもとに整理しました。資料が増えたときの動きと、メモリの分け方も載せています。

    中級者向け約25分整理するProjectsファイルの読み込みメモリ

  • 自分の文体の見本を渡して、書き方をそろえる

    自分が書いた文章を見本として渡し、Claudeのカスタムスタイルを作る方法です。思ったように写らないときの切り分けと、見本に入れてはいけないものも整理します。

    中級者向け約25分書く基本のチャットファイルの読み込み

  • くり返す手順を、スキルにまとめて自動で呼び出す

    毎回プロンプトを貼り直している作業を、スキル(手順書のフォルダ)にまとめる方法です。書く項目、ZIPにする形、呼び出されないときの見直し方、信頼できないスキルを入れるときの注意を、公式のヘルプをもとに整理しました。

    中級者向け約30分自動化するスキルファイルの読み込み

  • メモから、やることリストを取り出す

    打ち合わせのメモや議事録を貼る(またはファイルで渡す)と、「誰が・何を・いつまでに」を表にして取り出してもらう方法です。メモに書かれていない担当や期限は、空欄のまま残してもらいます。

    初心者向け約10分整理する基本のチャットファイルの読み込み

  • 写真を渡して、書かれている内容を表にする

    レシートや書類の写真をClaudeに渡し、日付・品目・金額の表にしてもらう方法です。表を信じる前に、合計が合うかを確かめる手順までを1セットにしています。

    初心者向け約10分整理するファイルの読み込み基本のチャット

  • Projectsに資料と指示を入れて、毎回の説明をなくす

    同じ話題で何度もClaudeに相談するとき、背景の説明を毎回書き直さなくて済むように、資料と指示をProjectにまとめておく方法です。

    初心者向け約15分整理するProjectsファイルの読み込み

  • 長い文章を貼って、要点と疑問点を出してもらう

    長い記事や資料を、全部読む前に「何が書いてあるか」「どこが怪しいか」をつかむ方法です。貼る・添付するの2通りと、読み違いを減らす聞き方をまとめました。

    初心者向け約10分学ぶ基本のチャットファイルの読み込み

  • README.mdに、構成と手順を書いて、Claudeに読ませる

    README.mdに、構成・手順・書式を書いておくと、人にもClaudeにも、作業の入口になります。書く項目と、読ませ方をまとめます。

    初心者向け約15分整理する基本のチャットファイルの読み込みClaude Code

  • sources.mdに、確認済みの出典をまとめて、毎回の調べ直しをなくす

    よく使う公式ページや、確認した書誌情報を、sources.mdにまとめて、確認した日つきで残す方法です。

    初心者向け約10分調べる基本のチャットファイルの読み込みWeb検索

  • todo.mdに、やることを書き出して、優先順位をClaudeと決める

    頭の中のやることを、todo.mdに書き出してClaudeに渡し、今日やることを3つに絞る方法です。

    初心者向け約10分整理する基本のチャットファイルの読み込み
