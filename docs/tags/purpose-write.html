文章を下書きして、直す。8件の活用方法があります。

  • Claude Codeに、READMEを書かせて、確認する

    Claude Codeに、プロジェクトのREADMEを書かせる手順です。READMEと、Claude用のメモ(CLAUDE.md)の違い、書かれたコマンドを実際に動かして確かめる方法、秘密の情報を載せないための点検まで書きました。

    中級者向け約25分書くClaude Code

  • Docsで、レポートの骨組みから作る

    いきなり本文を書かせると、読み手に合わない長い文章になりがちです。Claude Docsで、先に「骨組み(見出しと各節のねらい)」だけを作り、直してから本文を書いてもらう手順をまとめました。誰が読むか、何を決めたいかを先に伝えるのがコツです。

    初心者向け約15分書くDocs・Slides・Design基本のチャット

  • 自分の文体の見本を渡して、書き方をそろえる

    自分が書いた文章を見本として渡し、Claudeのカスタムスタイルを作る方法です。思ったように写らないときの切り分けと、見本に入れてはいけないものも整理します。

    中級者向け約25分書く基本のチャットファイルの読み込み

  • 同じ文章を、3つの言い方に書き分ける

    伝える内容は同じでも、相手によって言い方は変わります。1つの連絡文を、相手別に3つの文面へ書き分けてもらい、違いを比べて選ぶ方法をまとめました。

    初心者向け約10分書く基本のチャット

  • 相手と目的を伝えて、メールの下書きを作る

    「メールを書いて」だけで頼むと、ありきたりな文面になりがちです。相手、目的、言いたいこと、避けたいことを先に伝えて、下書きを作ってもらう方法をまとめました。

    初心者向け約10分書く基本のチャット

  • glossary.mdに、言葉の表記をそろえて、ぶれをなくす

    「活用方法」と「使い方」のように、ぶれやすい言葉を、glossary.mdで統一する方法です。

    初心者向け約10分書く基本のチャットProjects

  • rules.mdに、書くときの約束をまとめて、毎回守らせる

    「断定しない」「数字は出典を付ける」など、毎回伝えている約束を、rules.mdに1度まとめて、Claudeに守ってもらう方法です。

    初心者向け約15分書く基本のチャットProjects

  • style.mdに、文体の決まりを書いて、文章の調子をそろえる

    文の長さ、使わない言葉、見出しの型を、style.mdに書いて、Claudeの文章の調子をそろえる方法です。

    初心者向け約15分書く基本のチャットProjects
