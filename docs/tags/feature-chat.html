基本のチャット

ふつうの会話だけで試せる。28件の活用方法があります。

  • 大きな作業を、チェックリストに分けて進める

    一度では終わらない大きな作業を、段階に分け、各段階に「終わりの条件」をつけて進める方法です。最後に進捗メモを作らせ、会話が変わっても続きから始められます。確かめるのは自分です。

    中級者向け約25分整理する基本のチャット

  • 旅行の予定を、1日ごとの表にして、雨の日の案も作る

    行きたい場所と条件を伝えて、1日ごとの予定表にしてもらう方法です。余白の時間と、雨の日の代わりの案も、同じ表に入れます。営業時間や料金は、出発前に自分で確かめます。

    初心者向け約15分整理する基本のチャット

  • プロンプトを、Claudeに添削してもらって改善する

    「なんとなく頼んだら、微妙な答えだった」を、添削、試す、比べる、の3段で直す方法です。直す前に「うまくいった」の基準を決めておくので、直した結果が良くなったのかを、自分で判断できます。

    中級者向け約25分学ぶ基本のチャット

  • 同じ質問を2通りで聞いて、答えの食い違いを確かめる

    同じことを、聞き方を変えて別々の会話で2回聞き、答えを比べる方法です。食い違った所は、確かめる優先度が高い所です。ただし、一致したから正しい、とは言えません。最後の確認は、出典で行います。

    中級者向け約25分調べる基本のチャット

  • 分からない用語を、例え話で教えてもらう

    ニュースや会議で出てきた分からない用語は、検索しても説明が難しいことがあります。自分の立場と理由を伝えて、身近な例え話で教えてもらい、確認の1問で理解を試す方法をまとめました。

    初心者向け約10分学ぶ基本のチャット

  • 資料からクイズを作って、自分で練習する

    講義資料やテキストをClaudeに渡して、答え合わせつきのクイズを作り、間違えた所だけを復習する方法をまとめました。自分がどこで間違えるかが見えるので、読み返しの時間を絞れます。

    初心者向け約15分学ぶ基本のチャットファイルの読み込み

  • メモリに、答え方の好みを覚えてもらう

    毎回「結論から書いて」と頼むのをやめて、答え方の好みをClaudeのメモリに覚えてもらう方法をまとめました。覚えさせない設定と、覚えた内容の確認・削除の手順もあわせて載せています。

    初心者向け約10分整理するメモリ基本のチャット

  • Docsで、レポートの骨組みから作る

    いきなり本文を書かせると、読み手に合わない長い文章になりがちです。Claude Docsで、先に「骨組み(見出しと各節のねらい)」だけを作り、直してから本文を書いてもらう手順をまとめました。誰が読むか、何を決めたいかを先に伝えるのがコツです。

    初心者向け約15分書くDocs・Slides・Design基本のチャット

  • メモからスライドを作って、PowerPointで書き出す

    箇条書きのメモをClaudeに渡して、スライドの下書きを作り、PowerPointやPDFで書き出す方法です。直し方のコツと、書き出す前の点検リストもまとめました。

    初心者向け約15分作るDocs・Slides・Design基本のチャット

  • 自分の文体の見本を渡して、書き方をそろえる

    自分が書いた文章を見本として渡し、Claudeのカスタムスタイルを作る方法です。思ったように写らないときの切り分けと、見本に入れてはいけないものも整理します。

    中級者向け約25分書く基本のチャットファイルの読み込み

  • CoworkとClaude Codeの使い分けを、表と図で整理する

    CoworkとClaude Codeは、どちらも「作業を任せる」道具ですが、得意な仕事も、動く場所も、確認の出し方も違います。公式のヘルプとドキュメントをもとに、動き方、使い分け、メリットとデメリット、費用、安全面を、表と図で整理しました。

  • 同じ文章を、3つの言い方に書き分ける

    打ち合わせのメモや議事録を貼る(またはファイルで渡す)と、「誰が・何を・いつまでに」を表にして取り出してもらう方法です。メモに書かれていない担当や期限は、空欄のまま残してもらいます。

    レシートや書類の写真をClaudeに渡し、日付・品目・金額の表にしてもらう方法です。表を信じる前に、合計が合うかを確かめる手順までを1セットにしています。
