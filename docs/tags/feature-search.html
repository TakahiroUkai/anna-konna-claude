Web検索

最新の情報をWebから探してもらう。4件の活用方法があります。

  • Research機能で、複数の選択肢を比較する

    Research機能は、複数回の検索を重ねて調べてくれますが、使うほど「どの情報源まで見に行ったか」が見えにくくなります。比べる基準を先に決め、コネクタの扱いを確認し、大事な点は自分で出典を開いて確かめる手順を、公式のヘルプをもとに整理しました。

    中級者向け約25分調べるWeb検索コネクタ

  • Web検索で、気になる情報の裏付けを取る

    「本当かな?」と思った話を、そのまま信じも捨てもせずに、出典つきで確かめる方法です。主張を分けて、1つずつ出典をつけてもらい、最後は自分で出典を開いて確かめます。

    初心者向け約10分調べるWeb検索基本のチャット

  • 毎朝の情報まとめを、定期タスクで自動化する

    Claude Coworkの定期タスクで、決まった時間に情報まとめを作らせる方法です。条件が合わないと動かないので、動く条件と、最初の確認のしかたも整理します。

    中級者向け約30分自動化する定期タスクCoworkWeb検索

  • sources.mdに、確認済みの出典をまとめて、毎回の調べ直しをなくす

    よく使う公式ページや、確認した書誌情報を、sources.mdにまとめて、確認した日つきで残す方法です。

    初心者向け約10分調べる基本のチャットファイルの読み込みWeb検索
