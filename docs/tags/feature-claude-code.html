Claude Code

コードを書く・動かす作業を任せる。3件の活用方法があります。

  • CoworkとClaude Codeの使い分けを、表と図で整理する

    CoworkとClaude Codeは、どちらも「作業を任せる」道具ですが、得意な仕事も、動く場所も、確認の出し方も違います。公式のヘルプとドキュメントをもとに、動き方、使い分け、メリットとデメリット、費用、安全面を、表と図で整理しました。

    初心者向け約20分学ぶCoworkClaude Code基本のチャット

  • CLAUDE.mdに、作業の約束を置いて、Claude Codeに毎回読ませる

    Claude Codeは、作業のはじめにCLAUDE.mdを読みます。置き場所、書き方の目安、/initでの作り方を、公式ドキュメントをもとに整理します。

    中級者向け約20分自動化するClaude Code

  • README.mdに、構成と手順を書いて、Claudeに読ませる

    README.mdに、構成・手順・書式を書いておくと、人にもClaudeにも、作業の入口になります。書く項目と、読ませ方をまとめます。

    初心者向け約15分整理する基本のチャットファイルの読み込みClaude Code
