理解を深める、練習する。3件の活用方法があります。

  • 分からない用語を、例え話で教えてもらう

    ニュースや会議で出てきた分からない用語は、検索しても説明が難しいことがあります。自分の立場と理由を伝えて、身近な例え話で教えてもらい、確認の1問で理解を試す方法をまとめました。

    初心者向け約10分学ぶ基本のチャット

  • 資料からクイズを作って、自分で練習する

    講義資料やテキストをClaudeに渡して、答え合わせつきのクイズを作り、間違えた所だけを復習する方法をまとめました。自分がどこで間違えるかが見えるので、読み返しの時間を絞れます。

    初心者向け約15分学ぶ基本のチャットファイルの読み込み

  • 長い文章を貼って、要点と疑問点を出してもらう

    長い記事や資料を、全部読む前に「何が書いてあるか」「どこが怪しいか」をつかむ方法です。貼る・添付するの2通りと、読み違いを減らす聞き方をまとめました。

    初心者向け約10分学ぶ基本のチャットファイルの読み込み
