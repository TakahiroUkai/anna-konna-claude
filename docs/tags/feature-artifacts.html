使う機能

Artifacts

会話の横に作品(ツール・文書・ページ)を作る。10件の活用方法があります。

  • Artifactを更新して、前の版と見比べる

    作ったArtifactを直すときは、直す前の版を控えとして残し、Claudeに変更点の表を出させて、元の版と見比べます。公式のヘルプで確かめた直し方と、確かめられなかった点を分けて整理します。

    中級者向け約25分作るArtifacts

  • Claude Sheetsで、小さな予算表を作る

    Claude Sheets(Claudeの中で、表を作って直せる機能。ベータ)で、行事や買い物の小さな予算表を作ります。依頼文の型、数字の入れ方、合計の検算、.xlsxやCSVで書き出す方法までまとめました。

    初心者向け約15分作るArtifactsDocs・Slides・Design

  • Whiteboardsで、ふりかえりの意見をテーマ別に整理する

    ふりかえりで出た意見を、Claude Whiteboardsに書き出して、テーマ別に並べ直してもらいます。公式のヘルプで確かめた使い方と、そのまま貼れるプロンプト、出た結果の見直し方まで書きます。

    初心者向け約15分整理するArtifactsDocs・Slides・Design

  • Sheetsの数式を、検算して直してもらう

    Claude Sheetsが作った数式が正しいかを、答えの分かる数字で試して確かめます。範囲を選んで理由を聞く、直した場所を見る、前の版に戻す、といった公式の機能と、切り分けの順番、守るべき注意点まで書きます。

    中級者向け約25分作るArtifactsDocs・Slides・Design

  • Whiteboardsの発想を、担当と期限つきの計画にする

    Claude Whiteboardsに出した発想を、計画案(文書)に変えます。担当と期限は人が決める、という線引きと、抜けや順番のずれを確かめる手順、共有と書き出しの注意点まで書きます。

    中級者向け約25分整理するArtifactsDocs・Slides・Design

  • Artifactで、毎日の記録つきの習慣トラッカーを作る

    Artifactの保存機能を使って、閉じても記録が残る習慣トラッカーを作る方法です。個人用の保存と共有の保存の違い、記録が本当に残るかの確かめ方、共有する前に消すものまで整理します。

    中級者向け約25分作るArtifacts

  • Artifactで、自作のクイズアプリを作る

    覚えたい内容を渡して、Artifactで「答えると○×が出て、最後に点数が出る」クイズアプリを作る方法です。資料を読み返すより、答えるほうが弱い所が見えます。

    初心者向け約15分作るArtifacts

  • CSVを渡して、集計とグラフをArtifactで作る

    家計や売上のCSVをClaudeに渡して、集計表とグラフを会話の横に作る方法です。分析ツールの設定、集計が合っているかの確かめ方、うまくいかないときの切り分け、貼ってはいけないデータの線引きまで整理します。

    中級者向け約25分作るArtifactsファイルの読み込み

  • Artifactを共有する前の、点検リストを作る

    作ったArtifactを人に見せる前に、誰が見られるか、何が一緒に見えるかを確かめる方法です。公式のヘルプで確認できた共有の仕組みをもとに、点検リストと、Claudeに下見を頼む文章を用意します。

    中級者向け約20分作るArtifacts

  • Artifactで、割り勘の計算ツールを作る

    作りたいツールを言葉で伝えるだけで、会話の横に動くツールができます。割り勘の計算ツールを例に、作り方と、直し方、共有する前の注意点を整理します。

    初心者向け約15分作るArtifacts基本のチャット
