目的

整理する

資料やメモを整える、考えをまとめる。16件の活用方法があります。

  • 過去のチャットを探して、前回の続きから始める

    「あの話、どこだっけ」を、Claudeに頼んで探す方法です。過去のチャットの検索のしかた、元のチャットの確かめ方、探せない場合の原因と、検索の対象から外す方法を整理します。

    初心者向け約10分整理するメモリ基本のチャット

  • メモリと過去チャット検索の範囲を点検して、残すものを決める

    Claudeのメモリと過去チャット検索が、どこまでを覚え、どこまでを探せるのかを、公式のヘルプをもとに整理します。プロジェクトごとの分け方、1つのチャットだけ外す方法、チャットを消してもメモリが残る点、点検の手順と確かめ方まで書きます。

    中級者向け約25分整理するメモリProjects

  • 大きな作業を、チェックリストに分けて進める

    一度では終わらない大きな作業を、段階に分け、各段階に「終わりの条件」をつけて進める方法です。最後に進捗メモを作らせ、会話が変わっても続きから始められます。確かめるのは自分です。

    中級者向け約25分整理する基本のチャット

  • 旅行の予定を、1日ごとの表にして、雨の日の案も作る

    行きたい場所と条件を伝えて、1日ごとの予定表にしてもらう方法です。余白の時間と、雨の日の代わりの案も、同じ表に入れます。営業時間や料金は、出発前に自分で確かめます。

    初心者向け約15分整理する基本のチャット

  • コネクタで、予定を見ながら1日の計画を立てる

    Googleカレンダーのコネクタをつないで、Claudeに予定を読ませ、空き時間に作業を割り当てた計画を作る方法です。読ませる範囲の決め方、結果の確かめ方、公式の説明が食い違う点も整理します。

    中級者向け約25分整理するコネクタ

  • メモリに、答え方の好みを覚えてもらう

    毎回「結論から書いて」と頼むのをやめて、答え方の好みをClaudeのメモリに覚えてもらう方法をまとめました。覚えさせない設定と、覚えた内容の確認・削除の手順もあわせて載せています。

    初心者向け約10分整理するメモリ基本のチャット

  • Projectに複数の資料を入れて、役割を分けて使わせる

    Projectに資料を何でも入れると、答えの根拠が見えなくなります。資料に役割を決めて入れ、指示で使い分けさせ、根拠のファイル名を答えに付けさせる方法を、公式のヘルプをもとに整理しました。資料が増えたときの動きと、メモリの分け方も載せています。

    中級者向け約25分整理するProjectsファイルの読み込みメモリ

  • メモから、やることリストを取り出す

    打ち合わせのメモや議事録を貼る(またはファイルで渡す)と、「誰が・何を・いつまでに」を表にして取り出してもらう方法です。メモに書かれていない担当や期限は、空欄のまま残してもらいます。

    初心者向け約10分整理する基本のチャットファイルの読み込み

  • 写真を渡して、書かれている内容を表にする

    レシートや書類の写真をClaudeに渡し、日付・品目・金額の表にしてもらう方法です。表を信じる前に、合計が合うかを確かめる手順までを1セットにしています。

    初心者向け約10分整理するファイルの読み込み基本のチャット

  • 「質問してから答えて」と頼んで、条件を詰める

    答えを頼む前に、「先にあなたから質問して」と頼む方法です。決まっていないことをClaudeに聞き出してもらい、条件が固まってから答えてもらいます。

    初心者向け約10分整理する基本のチャット

  • Projectsに資料と指示を入れて、毎回の説明をなくす

    同じ話題で何度もClaudeに相談するとき、背景の説明を毎回書き直さなくて済むように、資料と指示をProjectにまとめておく方法です。

    初心者向け約15分整理するProjectsファイルの読み込み

  • decisions.mdに、決めた理由を残して、後で迷わないようにする

    「なぜそう決めたか」を、decisions.mdに1行ずつ残す方法です。後から見直すとき、Claudeにも前提を渡せます。

    初心者向け約10分整理する基本のチャットProjects

  • ideas.mdに、案をためて、Claudeと選び分ける

    思いついた案を、ideas.mdにいったんためておき、Claudeと「やる・待つ・やめる」に分ける方法です。

    初心者向け約10分整理する基本のチャット

  • log.mdに、やったことを日付つきで残して、続きから始める

    log.mdに、毎回の作業を数行ずつ残すと、翌日の続きがすぐ始められます。書く項目と、Claudeの使い方をまとめます。

    初心者向け約10分整理する基本のチャットProjects

  • README.mdに、構成と手順を書いて、Claudeに読ませる

    README.mdに、構成・手順・書式を書いておくと、人にもClaudeにも、作業の入口になります。書く項目と、読ませ方をまとめます。

    初心者向け約15分整理する基本のチャットファイルの読み込みClaude Code

  • todo.mdに、やることを書き出して、優先順位をClaudeと決める

    頭の中のやることを、todo.mdに書き出してClaudeに渡し、今日やることを3つに絞る方法です。

    初心者向け約10分整理する基本のチャットファイルの読み込み
