難易度、目的、使う機能の3つの軸で、活用方法を探せます。

難易度

  • 初心者向け 26件Claudeを使い始めた人でも、画面の操作だけで試せる。
  • 中級者向け 13件設定や考え方の理解が少し要る。いくつかの機能を組み合わせる。

目的

  • 調べる 4件情報を集めて、まとめる
  • 書く 8件文章を下書きして、直す
  • 作る 6件ツール、ページ、資料などを作る
  • 自動化する 3件くり返しの作業を任せる
  • 整理する 12件資料やメモを整える、考えをまとめる
  • 学ぶ 6件理解を深める、練習する

使う機能

  • 基本のチャット 33件ふつうの会話だけで試せる
  • ファイルの読み込み 13件文書や画像を渡して読んでもらう
  • Web検索 4件最新の情報をWebから探してもらう
  • Projects 8件資料と指示をまとめた作業場
  • Artifacts 5件会話の横に作品(ツール・文書・ページ)を作る
  • Docs・Slides・Design 4件文書、スライド、デザインを作る
  • メモリ 4件会話をまたいで覚えておいてもらう
  • 定期タスク 1件決まった時間に自動で実行する
  • Cowork 5件パソコン上で作業を任せる
  • コネクタ 4件他のアプリとつなぐ
