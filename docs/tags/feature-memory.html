メモリ

会話をまたいで覚えておいてもらう。4件の活用方法があります。

  • 過去のチャットを探して、前回の続きから始める

    「あの話、どこだっけ」を、Claudeに頼んで探す方法です。過去のチャットの検索のしかた、元のチャットの確かめ方、探せない場合の原因と、検索の対象から外す方法を整理します。

    初心者向け約10分整理するメモリ基本のチャット

  • メモリと過去チャット検索の範囲を点検して、残すものを決める

    Claudeのメモリと過去チャット検索が、どこまでを覚え、どこまでを探せるのかを、公式のヘルプをもとに整理します。プロジェクトごとの分け方、1つのチャットだけ外す方法、チャットを消してもメモリが残る点、点検の手順と確かめ方まで書きます。

    中級者向け約25分整理するメモリProjects

  • メモリに、答え方の好みを覚えてもらう

    毎回「結論から書いて」と頼むのをやめて、答え方の好みをClaudeのメモリに覚えてもらう方法をまとめました。覚えさせない設定と、覚えた内容の確認・削除の手順もあわせて載せています。

    初心者向け約10分整理するメモリ基本のチャット

  • Projectに複数の資料を入れて、役割を分けて使わせる

    Projectに資料を何でも入れると、答えの根拠が見えなくなります。資料に役割を決めて入れ、指示で使い分けさせ、根拠のファイル名を答えに付けさせる方法を、公式のヘルプをもとに整理しました。資料が増えたときの動きと、メモリの分け方も載せています。

    中級者向け約25分整理するProjectsファイルの読み込みメモリ
