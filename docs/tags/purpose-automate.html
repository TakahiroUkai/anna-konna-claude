自動化する

くり返しの作業を任せる。3件の活用方法があります。

  • くり返す手順を、スキルにまとめて自動で呼び出す

    毎回プロンプトを貼り直している作業を、スキル(手順書のフォルダ)にまとめる方法です。書く項目、ZIPにする形、呼び出されないときの見直し方、信頼できないスキルを入れるときの注意を、公式のヘルプをもとに整理しました。

    中級者向け約30分自動化するスキルファイルの読み込み

  • 毎朝の情報まとめを、定期タスクで自動化する

    Claude Coworkの定期タスクで、決まった時間に情報まとめを作らせる方法です。条件が合わないと動かないので、動く条件と、最初の確認のしかたも整理します。

    中級者向け約30分自動化する定期タスクCoworkWeb検索

  • CLAUDE.mdに、作業の約束を置いて、Claude Codeに毎回読ませる

    Claude Codeは、作業のはじめにCLAUDE.mdを読みます。置き場所、書き方の目安、/initでの作り方を、公式ドキュメントをもとに整理します。

    中級者向け約20分自動化するClaude Code
