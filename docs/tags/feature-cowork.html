Cowork

パソコン上で作業を任せる。2件の活用方法があります。

  • CoworkとClaude Codeの使い分けを、表と図で整理する

    CoworkとClaude Codeは、どちらも「作業を任せる」道具ですが、得意な仕事も、動く場所も、確認の出し方も違います。公式のヘルプとドキュメントをもとに、動き方、使い分け、メリットとデメリット、費用、安全面を、表と図で整理しました。

    初心者向け約20分学ぶCoworkClaude Code基本のチャット

  • 毎朝の情報まとめを、定期タスクで自動化する

    Claude Coworkの定期タスクで、決まった時間に情報まとめを作らせる方法です。条件が合わないと動かないので、動く条件と、最初の確認のしかたも整理します。
