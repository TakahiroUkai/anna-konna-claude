Claudeの機能

プロンプトぷろんぷと
Claudeに伝える依頼の文章です。誰に向けて、何を、どんな形で欲しいかを書くほど、思ったとおりの答えが返りやすくなります。
Project(プロジェクト)ぷろじぇくと
資料と指示をまとめて置いておく、Claudeの作業場です。同じ話題で何度も相談するときに、背景の説明を毎回書き直さずに済みます。
Artifact(アーティファクト)あーてぃふぁくと
会話の横に作られる、ツール、文書、ページなどの作品です。作ったものを、その場で動かしたり直したりできます。
メモリ(Claudeの機能)めもり
会話をまたいで、好みや前提を覚えておく機能です。覚えた内容は、設定で確認や削除ができます。なお、パソコンの部品としての「メモリ」は、別の用語(RAM)で説明しています。
スキルすきる
よく使う作業の手順をまとめた、手順書のフォルダです。Claudeが必要なときに呼び出して使います。
コネクタ(MCPコネクタ)こねくた
Claudeを、外部のアプリやサービスとつなぐ仕組みです。つなぐと、Claudeがそのサービスの情報を読んだり操作したりできるようになります。「MCP」は、そのつなぎ方を決めた共通の約束の名前です。
Cowork(コワーク)こわーく
パソコン上の作業を、Claudeに任せて進めてもらう機能です。ファイルの整理や、資料づくりなどを頼みます。
Claude Code(クロード コード)くろーど こーど
コードを書く、動かす、直す作業を、Claudeに任せる道具です。パソコンで使う方法と、クラウド上で使う方法があります。
定期タスクていきたすく
決まった時間に、自動で実行する作業です。一度説明しておくと、毎回頼まなくても動きます。
スタイル(カスタムスタイル)すたいる
Claudeの書き方の調子を選ぶ機能です。自分の文章を見本に渡して、自分用のスタイルを作ることもできます。
利用上限りようじょうげん
一定の期間に使える量の上限です。大きな依頼ほど、多く使います。上限に達すると、リセットされるまで待つことになります。
プラグインぷらぐいん
スキル、コネクタ、サブエージェントなどを、1つのパッケージにまとめたものです。入れると、まとめて使えるようになります。入れる前に、提供元と中身を確かめます。
分析ツールぶんせきつーる
Claudeがコードを動かして、計算やCSVの分析をする機能です。実行したコードは、答えのあとに確かめられます。
コンテキストウィンドウこんてきすとうぃんどう
1つの会話でClaudeが一度に読める量のことです。渡す文章やファイルが長すぎると、収まらないことがあります。
エージェントえーじぇんと
自分で計画を立て、道具(ファイルの読み書き、検索、コマンドの実行など)を使い、結果を見て次の手を決めて進むAIの動き方です。CoworkもClaude Codeも、このしくみで動きます。
サブエージェントさぶえーじぇんと
親のClaudeから仕事を分けてもらい、別の作業場で進めて、結果だけを返す小さなClaudeです。長い調べ物で会話がいっぱいになるのを防ぎ、仕事を並行して進められます。
MCPえむしーぴー
外部のアプリやデータとClaudeをつなぐ、共通の規格です。Slackやデータベースなどに、Claude Codeからつなぐときに使います。
プロンプトインジェクションぷろんぷと いんじぇくしょん
Webページやファイルの中に、AIへの悪意ある指示を紛れ込ませる攻撃です。AIが本来の依頼と取り違えて、危険な操作をするおそれがあります。
画面操作(computer use)がめんそうさ
Claudeが、画面を見ながらクリックや入力をして、パソコンのアプリを直接操作する機能です。ベータ版で、間にサンドボックスがないため、慎重に使います。
追加の使用量(usage credits)ついかのしようりょう
プランの上限に達したあとも、使った分だけ支払って使い続けるための仕組みです。標準のAPI料金で課金されます。
Remote Control(リモートコントロール)りもーと こんとろーる
手元のパソコンで動いているClaude Codeを、スマホやブラウザから操作する機能です。コードが動く場所は、手元のパソコンのままです。
ベータべーた
正式版の前に、試しに公開されている段階のことです。仕様が変わったり、一部の人にだけ提供されたりすることがあります。
Plaid(プレイド)ぷれいど
アプリと銀行をつなぐ会社の名前です。銀行の画面で本人がサインインして、アプリに見せる口座を選ぶ仕組みに使われます。
権限モード(パーミッションモード)けんげんもーど
Claude Codeが、ファイルの変更やコマンドの実行を、聞かずにやってよいかを決める設定です。画面の下の表示で、いまのモードが分かります。
プランモードぷらんもーど
Claude Codeが、ファイルを読んで計画を出すだけで、計画を承認するまでファイルを変えないモードです。作らせる前に、案を見たいときに使います。
文章の透かし(text watermark)ぶんしょうのすかし
AIが生成した文章に付ける、目印の仕組みです。Anthropicの公式ページでは、見える文字や記号を足すものではない、と説明されています。
プロジェクトタグぷろじぇくとたぐ
Enterprise向けのベータ機能で、プロジェクトに、費用の管理番号などのコードを付けます。付けたコードごとに、利用額をまとめて見られます。
Docs(ドキュメント)どきゅめんと
Claudeの中で、会話から作る文書です。自分で直したり、Claudeに直してもらったり、コメントで相談したりできます。
Design(デザイン)でざいん
Claudeの中で、画面やチラシなどの見た目を作る機能です。作ったものは、PDFなどに書き出せます。

クラウドセッション(Claude Code)

クラウドセッションくらうどせっしょん
自分のパソコンではなく、クラウド上のパソコンで、Claude Codeに作業させる使い方です。
環境(クラウド環境)かんきょう
クラウド上のパソコンが、どう始まるかを決める設定のまとまりです。接続先、設定値、入れる道具などを決めます。
仮想マシン(VM)かそうましん
クラウド上に用意される、作業用のパソコンです。セッションごとに、新しいものが使われます。
セッションせっしょん
Claudeに作業を頼み始めてから終わるまでの、ひとまとまりのやりとりです。
リポジトリりぽじとり
プログラムや文書のファイルと、その変更の記録をまとめて置く場所です。
GitHub(ギットハブ)ぎっとはぶ
プログラムなどを保管し、共同で使うためのサービスです。
ネットワークアクセス(None・Trusted・Full・Custom)ねっとわーくあくせす
外のどこに接続してよいかの設定です。None=接続なし、Trusted=許可リストだけ、Full=どこでも、Custom=自分で決めたリスト、の4段階です。
許可リストきょかりすと
接続してよい相手を並べた一覧です。一覧にない相手には、接続できません。
ドメインどめいん
「example.com」のような、インターネット上の住所の名前です。
サブドメインさぶどめいん
「api.example.com」の「api」のように、ドメインの前に付く名前です。「*.example.com」と書くと、すべてのサブドメインを指します。
ホストほすと
接続先のコンピューターの名前です。例:「api.example.com」。
パッケージぱっけーじ
他の人が作った、部品のようなプログラムです。取り込んで使います。npmはJavaScript用、PyPIはPython用の、配布先です。
SDKえすでぃーけー
あるサービスを、自分のプログラムから使うための部品と道具のまとまりです。
環境変数かんきょうへんすう
プログラムが読む、名前つきの設定値です。「LOG_LEVEL=debug」なら、名前が「LOG_LEVEL」、値が「debug」です。
引用符いんようふ
文字列の両端を囲む「"」や「'」です。値の途中の「#」が、コメントと誤解されるのを防ぎます。
コメントこめんと
プログラムが読み飛ばす、人間向けのメモの部分です。設定の書き方では、「#」から行の終わりまでが、これにあたります。
アイドルあいどる
しばらく何も操作がなく、休んでいる状態です。
ネットワークシークレットねっとわーくしーくれっと
APIキーなどの鍵を、Claudeに見せずに使わせる仕組みです。指定した接続先への通信にだけ、鍵が付きます。
APIキー・トークンえーぴーあいきー
サービスを使う権利を示す、合い言葉のような文字列です。他人に知られると、勝手に使われるおそれがあります。
ヘッダーへっだー
通信に付ける、追加情報の欄です。鍵は、ここに入れて送ります。
エージェントプロキシえーじぇんとぷろきし
通信を中継するAnthropicの仕組みです。指定した相手宛ての通信にだけ、鍵を付けます。
Bearer(ベアラー)べあらー
「この鍵を持つ人」として扱ってほしい、という種類の鍵の送り方です。
セットアップスクリプトせっとあっぷすくりぷと
作業の前に、一度だけ動かすスクリプトです。入っていない道具を入れるときに使います。
Bash(バッシュ)ばっしゅ
コマンドを順に実行するための、文字で操作する道具(シェル)です。
root(ルート)るーと
パソコンのすべてを変更できる、最も強い権限です。
apt(エーピーティー)えーぴーてぃー
Ubuntuというパソコンのソフトを入れる道具です。「apt install」で入れます。
終了コードしゅうりょうこーど
コマンドが終わったときに返す数字です。0は成功、それ以外は失敗を表します。
|| true(オア トゥルー)
直前のコマンドが失敗しても、成功したことにして先へ進める書き方です。止まっては困らない命令に付けます。
キャッシュきゃっしゅ
作業後の状態を保存して、次回から使い回す仕組みです。次の開始が速くなります。
並列へいれつ
複数の作業を同時に走らせることです。全部終わるのを待ってから、次へ進みます。
Dockerイメージどっかーいめーじ
アプリをそのまま動かせる形にまとめた、ひな形のファイルです。
フックふっく
決まった場面で、自動で動かす小さな処理です。
~/.claude/
自分のパソコンの中にある、Claude Codeの個人用の設定を置く場所です。クラウドのパソコンには、ここは届きません。
vCPUぶいしーぴーゆー
仮想マシンが使える、計算をする部品の数です。多いほど、同時に多くの処理をこなせます。
メモリ(パソコンの部品)めもり
作業中のデータを一時的に置く場所です。足りないと、重い作業が止まることがあります。Claudeの「メモリ」機能とは別のものです。
ディスクでぃすく
ファイルを保存しておく場所です。
Owner(オーナー)おーなー
組織の設定を管理できる役割です。Teamなどのプランで使われます。

ファイルと書き方

Markdownまーくだうん
見出しや箇条書きを、記号で書く文章の形式です。拡張子は .md です。
CLAUDE.mdくろーど えむでぃー
Claude Codeが、作業のはじめに読む指示書です。リポジトリに置いておくと、毎回同じ約束を伝えられます。
README.mdりーどみー
フォルダやリポジトリの入口になる説明書です。目的、構成、手順などを書きます。

ファイル

CSVしーえすぶい
カンマ(,)で区切って並べた、表のデータのファイルです。家計簿アプリや売上の管理ソフトから書き出せることが多く、表計算ソフトでも開けます。

開発まわりの言葉

ターミナルたーみなる
文字で命令を打ってパソコンを操作する画面です。Claude Codeは、ここから使うのが基本の形のひとつです。Coworkでは使いません。
Git(ギット)ぎっと
ファイルの変更の記録を残す仕組みです。いつ、何を、どう変えたかをさかのぼれるので、AIに直してもらう前の状態を残しておくのにも役立ちます。
ブランチぶらんち
Gitで、本編に影響しない作業用の枝分かれです。Claude Codeのクラウドセッションは、変更をこの枝に保存して返します。
プルリクエスト(PR)ぷるりくえすと
作業用のブランチの変更を、本編に取り込んでよいか確認してもらうための依頼です。変更の差分を見ながら、レビューして採用を決めます。
IDE(アイディーイー)あいでぃーいー
プログラムを書くための専用ソフトです。VS CodeやJetBrains製のソフトが代表的で、Claude Codeを組み込んで使えます。
CI/CDしーあい しーでぃー
コードを変更するたびに、テストや公開を自動で行う仕組みです。GitHub ActionsやGitLab CI/CDが代表例で、Claude Codeを自動レビューなどに組み込めます。
サンドボックスさんどぼっくす
外から切り離した安全な箱です。その中で動くプログラムは、箱の外のファイルや通信に触れにくくなります。

道具

git(ギット)ぎっと
ファイルの変更の履歴を残す道具です。コミットという区切りを作っておくと、あとで変更を見比べたり、元に戻したりできます。

API

Messages APIめっせーじえーぴーあい
自分のプログラムから、Claudeに文章を送って答えを受け取るための窓口です。送る内容のまとまりを、リクエストと呼びます。

モデル

Fable・Mythos(フェイブル・ミトス)ふぇいぶる・みとす
Anthropicのモデルの名前です。同じ基盤で、Fableは全ユーザー向け、Mythosは審査を受けた組織向けと、公式発表で説明されています。

ホームにもどる

このサイトについて 個人が運営する非公式のサイトです。Anthropic社とは関係ありません。「Claude」はAnthropic社の商標です。

ご利用にあたって 一般的な情報の整理であり、結果を保証するものではありません。機能、画面、料金、提供プランは変わることがあるため、各ページの出典(公式情報)と、お使いの画面で確認してください。AIの答えには誤りが含まれることがあります。大事な内容は、自分で確かめてから使ってください。

広告について このサイトには、書籍紹介のアフィリエイトリンク(広告)が含まれます。リンク先で購入されると、運営者に報酬が入ることがあります。Amazonのアソシエイトとして、あんなことこんなことClaudeは適格販売により収入を得ています。
