Claudeには、使い始めたときには気づきにくい使い方がたくさんあります。ここでは、1つの使い方を、手順、そのまま貼って使えるプロンプト、つまずきやすい点まで、同じ形式で整理します。まず1つ、手を動かして試してみてください。

探し方

難易度
初心者向け 画面の操作だけで試せます。中級者向け 設定や、複数の機能の組み合わせが要ります。
目的
調べる、書く、作る、自動化する、整理する、学ぶ、のどれにあたるかです。
使う機能
Projects、Artifacts、定期タスクなど、使う機能で絞れます。

活用方法の一覧

  • Projectsに資料と指示を入れて、毎回の説明をなくす

    同じ話題で何度もClaudeに相談するとき、背景の説明を毎回書き直さなくて済むように、資料と指示をProjectにまとめておく方法です。

    初心者向け約15分整理するProjectsファイルの読み込み

  • Artifactで、割り勘の計算ツールを作る

    作りたいツールを言葉で伝えるだけで、会話の横に動くツールができます。割り勘の計算ツールを例に、作り方と、直し方、共有する前の注意点を整理します。

    初心者向け約15分作るArtifacts基本のチャット

  • 毎朝の情報まとめを、定期タスクで自動化する

    Claude Coworkの定期タスクで、決まった時間に情報まとめを作らせる方法です。条件が合わないと動かないので、動く条件と、最初の確認のしかたも整理します。
