結論から書きます。Artifactで作った習慣トラッカーは、記録を保存できます。ただし、作った直後に「閉じて開き直しても残るか」を必ず確かめます。残ると思い込んで毎日つけ、数週間分が消えていた、が一番つらい失敗だからです。

「三日坊主になりがちで、紙の表にも手帳にも続かなかった」という友人に、そのまま見せられる使い方です。

## ねらい

- Artifact(会話の横に作る、ツールやページ)で、毎日チェックできる習慣トラッカーを作ります。
- 記録が残ることを、自分の手で確かめます。
- 人に見せる前に、見られて困る記録が入っていないかを点検します。

## 準備するもの

- 公式のヘルプには、Artifactがセッションをまたいでデータを保存できる、と書かれています(2026年11月11日に確認)。この保存の機能の対象は、Pro、Max、Ultra、Team、Enterpriseで、claude.aiのWebとClaude Desktopと書かれています。Freeは、対象の一覧に入っていませんでした。自分のプランで使えるかは、画面で確かめます。
- Artifactを作るための設定。公式のヘルプには、「Settings > Capabilities」の「Cloud code execution and file creation」をオンにする、と書かれています。
- 続けたい習慣を、1つか2つ。最初は「水を飲む」「5分歩く」のような、小さなものにします。
- 練習のあいだは、体調や健康の細かい記録、他人の個人情報は入れません。

## 手順

:::flow 図: トラッカーを作って、残ることを確かめるまで
習慣と形を決める | 習慣は1〜2つ。見たい期間(今月)を決める
Artifactを頼む | 下のプロンプトで、保存の方式も書いて頼む
今日の分をつける | チェックを入れて、数字や表示が変わるか見る
閉じて開き直す | 会話を離れ、別の日に開いて、記録が残るか見る
保存の範囲を確かめる | 自分だけの保存か、共有の保存かを、Claudeに答えさせる
:::

1. **習慣と形を決めます。** 「毎日チェックを入れる」「今月の達成日数を出す」くらいの、小さな形にします。
2. **保存の方式を指定して頼みます。** 公式のヘルプには、保存には2種類あると書かれています。個人用の保存は、記録がその人だけに見えます。共有の保存は、開いた全員が同じデータを見て、書き込めます。自分の記録は、個人用の保存を指定します。
3. **今日の分をつけます。** チェックを入れて、達成日数が変わることを見ます。
4. **閉じて開き直します。** 画面を閉じて、少し時間を置いて、同じArtifactを開きます。チェックが残っていれば、保存は効いています。
5. **保存の範囲を、Claudeに確かめます。** 下の「確かめ」のプロンプトで、個人用と共有のどちらを使っているかを答えさせます。

画面の表示は変わることがあります。

:::compare 図: 保存の2種類(公式のヘルプの説明)
種類 | 見える人と使いどころ
個人用の保存 | 記録は、その人だけに見える。自分の習慣、日記、メモ向き
共有の保存 | 開いた全員が、同じデータを見て使う。みんなで使う得点表など。初めて使うときは、データが他の人に見える、という確認が出る
:::

## そのまま使えるプロンプト

:::prompt トラッカーを作る
Artifactで、習慣トラッカーを作ってください。
- 習慣: 「水を2リットル飲む」「5分歩く」の2つ。
- 画面: 今月のカレンダー形式で、日ごとに、習慣ごとのチェックを入れられる。
- 集計: 今月の達成日数を、習慣ごとに表示する。今日の日付に印をつける。
- 保存: チェックの記録は、保存して、閉じて開き直しても残るようにする。保存は、自分だけに見える個人用の保存にする。
- 見た目: スマホで見やすく、ボタンは押しやすい大きさにする。
- 入力できるのは、チェックの入り切りだけにする(自由な文章の欄は作らない)。
作り終えたら、保存の方式(個人用か共有か)と、保存されるデータの中身を、3行で説明してください。
:::

:::prompt 保存と共有を確かめる
今のArtifactについて、次の4点に答えてください。
1. 記録は、個人用の保存と共有の保存のどちらに入りますか。
2. 保存されるデータの項目を、すべて挙げてください。
3. このArtifactを他の人に共有すると、その人から、私の記録は見えますか。
4. 分からないことは、「分かりません」と書いて、私が自分の画面で確かめる手順を教えてください。
:::

## 実際の出力例

この記事のプロンプトは、この文章を書いた環境では実際に動かせていません(保存を確かめるには、Claudeの画面でArtifactを作り、閉じて開き直す操作が必要なためです)。そのため、出力は載せません。自分で動かしたときの確かめ方を書きます。

- チェックを入れた直後に、達成日数が増えるかを見ます。
- 画面を閉じて、少し時間を置いて開き直し、チェックが残っているかを見ます。残らなければ、保存が効いていません。作り直す前に、「保存が効いていないようです。保存の方式を直してください」と頼みます。
- 「保存と共有を確かめる」への答えが、画面での見え方と合っているかを見ます。たとえば、自分用のつもりが「共有の保存」と答えたら、作り直しを頼みます。

## 使いどころと失敗例

向く場面は、毎日、数秒でつける記録です。習慣、気分の一言、飲んだ水の量などです。公式のヘルプには、ジャーナルやトラッカーのようなものを作れる、と書かれています。

向かない場面は、消えると困る大事な記録です。保存の容量の上限は、公式のヘルプでは、1つのArtifactあたり20MBで、テキストだけです。写真やファイルは入れられません。大事な記録は、定期的に、別の場所に写して残します。

よくある失敗と、その直し方です。

- **保存の指定を書かずに頼み、開き直したら空になる。** 「閉じて開き直しても残る保存にする」と、頼み直します。
- **自分の記録のつもりが、共有の保存になっている。** 公式のヘルプには、どのデータを個人用にし、どれを共有にするかは、作る人が決める、と書かれています。共有の保存だと、開いた人に記録が見えます。「個人用の保存に直してください」と頼みます。
- **古い方式のArtifactを、公開をやめて消してしまう。** 公式の「Share artifacts」には、2026年9月16日より前の会話で作った古い方式のArtifactは、公開をやめると、保存した個人用と共有のデータが完全に消える、と書かれています。公開をやめる前に、記録を写して残します。
- **共有してから、記録が見られていたと気づく。** 公式の「Share artifacts」には、保存した情報が、開いた全員に見える場合がある、と書かれています。共有の前に、次の点検をします。

:::note 共有する前の点検
- 保存されているデータの中身を、Claudeに全部挙げさせる。
- 見られて困る記録(体調、場所、他人の名前)が入っていたら、消すか、練習用の別のArtifactを作って渡す。
- 共有の範囲を確認する。公式には、初めは自分だけに見えると書かれています。リンクを知っている人全員に見える設定にしていないかを見る。
:::

## うまくいかないとき

1. **保存の機能が見つからない、または保存されない。** 自分のプランが、保存の対象に入っているかを、公式のヘルプで見ます。Freeは、対象の一覧にありませんでした。
2. **設定が出ない。** 「Settings > Capabilities」で、「Cloud code execution and file creation」がオンか見ます。名前や場所は、画面の更新で変わることがあります。
3. **開き直したら、一部のチェックだけ消えている。** 「どの操作で保存されるか」と「保存のタイミング」を、Claudeに説明させます。保存を押す操作が要る作りなら、「チェックを入れるたびに保存する」に直してもらいます。
4. **他の人から見たら、自分の記録が見えた。** 共有の保存を使っています。個人用の保存に直してもらい、共有をいったんやめます。
5. **他の人のArtifactを開くとき。** 公式のヘルプには、信頼できる人から共有されたものだけを開く、と書かれています。

確認できなかったこと(保存の仕組みの細かい動き、保存データの書き出し方法)は、この記事では決めつけません。必要な場合は、自分の画面と、公式のヘルプで確かめてください。
