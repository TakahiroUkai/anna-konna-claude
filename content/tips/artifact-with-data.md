月末に、家計の明細や売上のCSVを開いて、表計算ソフトで合計を出す。この手間を、Claudeに任せられます。CSV(カンマで区切った表のファイル)を渡すと、月ごとの合計表と棒グラフを、会話の横に作ってくれます。ただし、出た数字はそのまま信じず、元データと照らして確かめるところまでが、この活用方法です。

## ねらい

- CSVを会話に渡して、月ごとの合計表と棒グラフを作ります。
- 集計が合っているかを、実行されたコードと、手元の数字で確かめます。
- 個人情報を含む列を、渡す前に外す習慣をつけます。

## 準備するもの

- 集計したいCSV。家計簿アプリの書き出しや、売上の一覧など。100行ほどの小さなものから始めます。
- 手元で合計を出せる道具。確かめに使います。
- 分析ツール(Claudeがコードを動かして、計算やCSVの分析をする機能)がオンであること。公式のヘルプでは、「Settings > Profile」の「Feature Preview」にある「Analysis tool」をオンにする、と書かれています。ヘルプには、先にArtifactが使える状態である必要がある、とも書かれています。
- Artifactの設定。公式のヘルプでは、Artifactの作成に「Cloud code execution and file creation」が要ると書かれています(Free・Pro・Maxは「Settings > Capabilities」)。
- 設定の名前や場所は、画面の更新で変わることがあります。自分のプランでどの項目が出るかは、この記事では確認できていません。見つからないときは、公式のヘルプを見直します。

## 手順

:::flow 図: CSVを渡して、確かめるまで
列を整える | 名前、口座番号など、集計に要らない列を外す
CSVを渡す | 会話にファイルを入れて、やりたい集計を具体的に頼む
グラフを頼む | 「棒グラフで」と、はっきり書く
分析を見る | 「View analysis」で、実行されたコードと出力を開く
手元と照合する | 合計や件数を、手元の数字と見比べる
:::

1. **列を整える。** 集計に使わない列(氏名、口座の番号、住所など)は、渡す前に消します。元のファイルは残し、コピーを編集します。
2. **CSVを渡す。** 公式のヘルプによると、CSVはチャットにアップロードし、分析したい内容を具体的に頼みます。
3. **グラフを頼む。** ヘルプには、グラフは明示的に頼むと作られやすい、と書かれています。図表はArtifactとして作られます。
4. **「View analysis」を開く。** 答えのあとに出るこの表示から、実行されたコードと出力が見られます。どの列を、どう足したかが分かります。
5. **手元の数字と照合する。** 全体の合計、行数、1か月分の合計を、手元で出して見比べます。

## そのまま使えるプロンプト

:::prompt 集計とグラフを頼む
添付のCSVを集計してください。
- 列の意味: 日付(YYYY-MM-DD)、項目、金額(円)
- 集計: 月ごとの金額の合計を表にする。項目ごとの内訳も付ける。
- グラフ: 月ごとの合計を、棒グラフにする。
- 金額は、3桁ごとにカンマを入れる。
条件:
- 先に、読み込んだ行数と、全体の合計金額を書いてください。私の手元の数字と見比べます。
- 日付が読み取れない行や、金額が空の行は、集計に入れず、行番号を一覧にしてください。
:::

:::prompt 確かめを頼む
今の集計について、次のことを答えてください。
1. どの列を、どう足したか(コードの流れを3行で)
2. 集計から外した行があれば、その理由
3. 数字が合わないとき、まず疑う場所を3つ
分かる範囲で答え、分からないことは「分かりません」と書いてください。
:::

## うまくいかないとき

:::compare 図: 数字が合わないときの切り分け(例)
疑う場所 | 確かめ方
行数が違う | 最初に書かせた行数と、手元の行数を比べる。違えば、読み込みの段階の問題
日付が崩れている | 日付の形式を、プロンプトで指定し直す
金額に「円」や「,」が混じる | 数字だけの列に直してから、渡し直す
合計だけ違う | 外した行の一覧を見て、集計に入れるかを決める
:::

- **ファイルが大きすぎるとき**: 公式のヘルプには、ファイルは会話のコンテキストウィンドウ(1つの会話で扱える量)に収まる必要がある、と書かれています。具体的な大きさの上限の数字は、ヘルプに書かれていませんでした。期間を分けて渡します。
- **グラフが出ないとき**: 「棒グラフにしてください」と、はっきり頼み直します。
- **分析の設定が見つからないとき**: 画面の名前が変わっている可能性があります。公式のヘルプで、今の設定の場所を見直します。
- **会社のデータのとき**: 社外に出せないデータや、他人の個人情報が入った明細は、貼りません。使ってよいかは、会社の決まりに従います。
- **結果を人に見せるとき**: 数字は、Claudeが作ったものです。手元で照合したあとで、使います。
